# **คำอธิบายรายวิชา**

รายวิชานี้ออกแบบมาสำหรับนักศึกษาที่ไม่มีพื้นฐานด้านข้อมูลมาก่อน
มุ่งเน้นการสร้างความเข้าใจพื้นฐานด้าน Data Analytics
และการนำไปประยุกต์ใช้ในบริบทธุรกิจและการตลาด
ผ่านการเรียนรู้แบบผสมผสานระหว่างทฤษฎีและปฏิบัติในคาบเดียวกัน โดยใช้เครื่องมือหลักคือ
Microsoft Excel เนื้อหาครอบคลุมตั้งแต่การทำความเข้าใจประเภทของข้อมูล
การทำความสะอาดข้อมูล สถิติเชิงพรรณนา การสร้างกราฟและ Dashboard
การวิเคราะห์เชิงการตลาด ไปจนถึงการนำเสนอผลการวิเคราะห์ข้อมูลอย่างมีประสิทธิภาพ (Data
Storytelling) ผู้เรียนจะได้ฝึกปฏิบัติจริงผ่านกรณีศึกษาที่ใกล้เคียงกับธุรกิจจริงตลอดวิชา
และจบรายวิชาด้วยการทำโปรเจกต์กลุ่มวิเคราะห์ข้อมูลจริง พร้อมนำเสนอผลลัพธ์ในคาบสุดท้าย

# **ผลลัพธ์การเรียนรู้ของรายวิชา**

เมื่อเรียนจบรายวิชานี้ นักศึกษาจะสามารถ:

1.  อธิบายแนวคิดพื้นฐานของ Data Analytics และจำแนกประเภทของข้อมูลทางธุรกิจได้

2.  ใช้ Excel ในการจัดการ ทำความสะอาด และวิเคราะห์ข้อมูลเชิงสถิติเบื้องต้นได้

3.  สร้างกราฟและ Dashboard ด้วย Excel เพื่อสื่อสารข้อมูลได้อย่างมีประสิทธิภาพ

4.  วิเคราะห์ข้อมูลเชิงการตลาด เช่น customer segmentation, conversion funnel,
    campaign metrics และแนวคิด A/B testing เบื้องต้นได้

5.  นำเสนอผลการวิเคราะห์ข้อมูล (Data Storytelling)
    และประยุกต์ใช้กับโจทย์ธุรกิจจริงในรูปแบบโปรเจกต์กลุ่มได้

# **หมายเหตุสำหรับผู้สอน**

- โปรเจกต์กลุ่มควรประกาศโจทย์และ dataset ตั้งแต่ครั้งที่ 7–8
  เพื่อให้นักศึกษาเริ่มเก็บ/สำรวจข้อมูลคู่ขนานไปกับการเรียน

- แต่ละคาบ 2 ชั่วโมง แนะนำแบ่งเป็นบรรยาย 40–45 นาที และปฏิบัติจริง 60–70 นาที
  เพื่อให้ทันเนื้อหาและได้ลงมือทำ

- ทุกคาบควรใช้ชุดข้อมูลตัวอย่างที่ใกล้เคียงกับธุรกิจจริง (ยอดขาย, แคมเปญ, ลูกค้า)
  เพื่อให้เชื่อมโยงกับสายบริหาร/การตลาดตลอดวิชา

- Quiz แนะนำให้เป็นแบบสถานการณ์ (scenario-based) มากกว่าสูตรคำนวณ เพื่อวัด
  “การตีความ” ซึ่งตรงกับเป้าหมายวิชานี้มากกว่าความลึกทางเทคนิค
