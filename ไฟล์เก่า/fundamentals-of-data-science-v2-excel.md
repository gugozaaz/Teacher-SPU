## คำอธิบายรายวิชา

รายวิชานี้ออกแบบมาสำหรับนักศึกษาที่ไม่มีพื้นฐานด้านเทคโนโลยีหรือข้อมูลมาก่อน มุ่งเน้นการสร้างความเข้าใจกระบวนการทางวิทยาการข้อมูล (Data Science) อย่างครบวงจร และการนำไปประยุกต์ใช้ในบริบทของการเป็นเจ้าของธุรกิจ ผ่านการเรียนรู้แบบผสมผสานระหว่างทฤษฎีและปฏิบัติในคาบเดียวกัน โดยใช้ Microsoft Excel เป็นเครื่องมือหลัก เสริมด้วยเครื่องมือ AI (เช่น ChatGPT, Google AI Studio) เพื่อให้ผู้เรียนเห็นภาพการทำงานร่วมกันระหว่างเครื่องมือดั้งเดิมและเทคโนโลยีใหม่

เนื้อหาครอบคลุมตั้งแต่การคิดแบบนักวิทยาการข้อมูล (Data Thinking) การตั้งคำถามและสมมติฐานทางธุรกิจ การเก็บและจัดการข้อมูล การวิเคราะห์เชิงสำรวจ (Exploratory Data Analysis) สถิติพื้นฐานสำหรับการตัดสินใจทางธุรกิจ การพยากรณ์เบื้องต้น การรู้จัก AI/Machine Learning ในระดับที่เจ้าของธุรกิจสามารถนำไปใช้ได้จริง ไปจนถึงการสร้าง Dashboard และการสื่อสารผลลัพธ์ข้อมูลอย่างมีประสิทธิภาพ (Data Storytelling)

ผู้เรียนจะได้ฝึกปฏิบัติจริงผ่านกรณีศึกษาที่ใกล้เคียงกับธุรกิจจริงตลอดรายวิชา และจบรายวิชาด้วยการทำโปรเจกต์กลุ่มวิเคราะห์ข้อมูลจริง พร้อมนำเสนอผลลัพธ์ในคาบสุดท้าย

> **หมายเหตุ — ความแตกต่างจากวิชา Data Analytics for Business**
> แม้ทั้งสองวิชาใช้ Microsoft Excel เป็นเครื่องมือหลักเหมือนกัน แต่มีจุดเน้นที่ต่างกัน:
> - **Data Analytics for Business** → เน้น "การวิเคราะห์ข้อมูลเชิงการตลาด" (PivotTable, RFM, Campaign Metrics, A/B Testing)
> - **Fundamentals of Data Science** → เน้น "กระบวนการทางวิทยาการข้อมูลทั้งวงจร" (Data Thinking, การตั้งสมมติฐาน, EDA, สถิติเชิงธุรกิจ, การพยากรณ์, AI/ML เบื้องต้น, Data Storytelling)

## ผลลัพธ์การเรียนรู้ของรายวิชา

เมื่อเรียนจบรายวิชานี้ นักศึกษาจะสามารถ:

1. **อธิบายแนวคิดพื้นฐานของ Data Science** รวมถึงกระบวนการทำงาน และจำแนกประเภทของข้อมูลที่เกี่ยวข้องกับธุรกิจได้
2. **ตั้งคำถามและสมมติฐานทางธุรกิจอย่างเป็นระบบ** โดยใช้แนวคิด Data Thinking เพื่อวางแผนการเก็บและวิเคราะห์ข้อมูลได้
3. **เก็บ จัดการ ทำความสะอาด และสำรวจข้อมูลเบื้องต้น** ด้วย Microsoft Excel เพื่อเตรียมข้อมูลให้พร้อมสำหรับการวิเคราะห์ได้
4. **วิเคราะห์ข้อมูลเชิงสถิติพื้นฐาน พยากรณ์แนวโน้ม และรู้จักการใช้ AI/Machine Learning** ในระดับที่เจ้าของธุรกิจสามารถนำไปตัดสินใจและสื่อสารกับทีมเทคนิคได้
5. **สร้าง Dashboard และนำเสนอผลการวิเคราะห์ข้อมูล (Data Storytelling)** ประยุกต์ใช้กับโจทย์ธุรกิจจริงในรูปแบบโปรเจกต์กลุ่มได้

## แผนการสอนรายครั้ง

### Module 1: รู้จัก Data Science และ Data Thinking (ครั้งที่ 1–3)

| ครั้งที่ | หัวข้อ | เนื้อหาหลัก | ปฏิบัติ / Quiz |
|---------|--------|-------------|----------------|
| **ครั้งที่ 1** | Data Science คืออะไร และทำไมเจ้าของธุรกิจต้องรู้ | Data Science vs Data Analytics — ต่างกันอย่างไร · กระบวนการทำ Data Science (CRISP-DM แบบเข้าใจง่าย: ตั้งคำถาม → เก็บข้อมูล → เตรียมข้อมูล → วิเคราะห์ → สื่อสาร) · ตัวอย่างธุรกิจที่ใช้ Data Science: Grab (การจัดเส้นทาง), LINE MAN (แนะนำร้าน), ร้านกาแฟ Amazon (พยากรณ์สต็อก), Shopee (ระบบแนะนำสินค้า) · ทักษะด้านข้อมูลที่เจ้าของธุรกิจยุคใหม่ควรมี · แนะนำ Excel เบื้องต้นที่ใช้ตลอดวิชา | **Workshop:** กิจกรรม "Data ในชีวิตประจำวัน" — สำรวจว่าในหนึ่งวันของธุรกิจ (ร้านค้า, ร้านอาหาร, ร้านออนไลน์) มีข้อมูลอะไรเกิดขึ้นบ้าง + เขียนคำถามทางธุรกิจ 5 ข้อที่ข้อมูลช่วยตอบได้ + เปิดไฟล์ข้อมูลตัวอย่างใน Excel ดูโครงสร้างเบื้องต้น · **Quiz:** ระบุว่าสถานการณ์ธุรกิจต่อไปนี้ใช้ Data Science ในขั้นตอนไหนของกระบวนการ |
| **ครั้งที่ 2** | Data Thinking — คิดแบบนักวิทยาการข้อมูล | การตั้งคำถามที่ดี (Asking the Right Questions) — คำถามที่ดีสำหรับธุรกิจเป็นอย่างไร · Hypothesis Thinking — การตั้งสมมติฐานก่อนลงมือวิเคราะห์ · 4 ระดับการวิเคราะห์: Descriptive (เกิดอะไรขึ้น), Diagnostic (ทำไมถึงเกิด), Predictive (จะเกิดอะไร), Prescriptive (ควรทำอะไร) · ตัวอย่างการตั้งสมมติฐานทางธุรกิจจริง | **Workshop:** กิจกรรม "ถ้าฉันเป็นเจ้าของธุรกิจ" — แบ่งกลุ่ม จำลองสถานการณ์ธุรกิจ (ร้านชานม, แบรนด์เสื้อผ้าออนไลน์, ฟู้ดทรัค) ให้ตั้งคำถาม ตั้งสมมติฐาน ระบุข้อมูลที่ต้องใช้ และจัดประเภทว่าเป็นการวิเคราะห์ระดับไหน · **Quiz:** จับคู่คำถามธุรกิจกับประเภทการวิเคราะห์ (Descriptive / Diagnostic / Predictive / Prescriptive) |
| **ครั้งที่ 3** | ประเภทข้อมูลและแหล่งข้อมูลสำหรับธุรกิจ | ประเภทข้อมูล: Structured vs Unstructured · เชิงปริมาณ (Quantitative) vs เชิงคุณภาพ (Qualitative) · แหล่งข้อมูลภายใน: POS, CRM, Website Analytics, ระบบบัญชี · แหล่งข้อมูลภายนอก: Open Data, Social Media, Market Research, Google Trends · ข้อมูลปฐมภูมิ vs ทุติยภูมิ · จริยธรรมข้อมูลและ PDPA — เจ้าของธุรกิจต้องรู้อะไรบ้าง · การนำเข้าข้อมูลจากแหล่งต่างๆ สู่ Excel (Import CSV, Text-to-Columns, Power Query เบื้องต้น) | **Workshop:** สำรวจแหล่ง Open Data ของไทย (data.go.th, Google Trends Thailand) + ดาวน์โหลดชุดข้อมูลจริง + Import เข้า Excel ด้วยวิธีต่างๆ (CSV, Copy-Paste, Power Query) + สร้างแผนการเก็บข้อมูล (Data Collection Plan) สำหรับธุรกิจจำลองที่ได้จากคาบ 2 · **Quiz:** จำแนกประเภทข้อมูลจากตัวอย่าง + เลือกแหล่งข้อมูลที่เหมาะกับโจทย์ธุรกิจ |

### Module 2: การจัดการและเตรียมข้อมูล (ครั้งที่ 4–6)

| ครั้งที่ | หัวข้อ | เนื้อหาหลัก | ปฏิบัติ / Quiz |
|---------|--------|-------------|----------------|
| **ครั้งที่ 4** | การเก็บข้อมูลและจัดเก็บอย่างเป็นระบบ | การออกแบบแบบสำรวจที่ดี (Microsoft Forms): หลักการตั้งคำถาม, ประเภทคำตอบ (Multiple choice, Scale, Open-ended) · การจัดเก็บข้อมูลใน Excel อย่างถูกต้อง (Tidy Data): 1 แถว = 1 รายการ, 1 คอลัมน์ = 1 ตัวแปร · การใช้ Excel Table (Format as Table) เพื่อจัดโครงสร้างข้อมูล · Data Dictionary — ทำไมต้องมีคู่มืออธิบายข้อมูล · ข้อผิดพลาดที่พบบ่อยในการเก็บข้อมูล (Merged Cells, ข้อมูลปนกัน, ไม่มีรหัส, ชีตเดียวใส่ทุกอย่าง) | **Workshop:** ออกแบบ Microsoft Forms สำรวจพฤติกรรมลูกค้าสำหรับธุรกิจจำลอง (10–15 คำถาม) + ส่ง Forms ให้เพื่อนในห้องตอบ + Export Response เข้า Excel + จัดรูปแบบเป็น Excel Table + เขียน Data Dictionary ลงชีตแยก · **Quiz:** ระบุข้อผิดพลาดในชุดข้อมูลตัวอย่างที่ให้มา (5 จุด) |
| **ครั้งที่ 5** | การทำความสะอาดข้อมูล (Data Cleaning) | ทำไมข้อมูลจริงถึง "สกปรก" — ตัวอย่างจริงจากธุรกิจ · ปัญหาที่พบบ่อย: ข้อมูลซ้ำ (Duplicates), ข้อมูลขาดหาย (Missing Values), รูปแบบไม่สม่ำเสมอ (Inconsistent Format), ค่าผิดปกติ (Outliers) · เทคนิคใน Excel: Remove Duplicates, TRIM, CLEAN, PROPER, Find & Replace, Text-to-Columns, Data Validation, Conditional Formatting เพื่อตรวจจับปัญหา, Flash Fill · กระบวนการ Data Cleaning แบบเป็นขั้นตอน | **Workshop:** ลงมือทำความสะอาดชุดข้อมูลยอดขายร้านค้า (Dataset ที่อาจารย์เตรียมให้ — มีข้อมูลซ้ำ, ชื่อสินค้าพิมพ์ผิด, วันที่หลายรูปแบบ, ราคาว่าง, ช่องว่างเกิน) + บันทึกขั้นตอนที่ทำ (Data Cleaning Log ในชีตแยก) · **Quiz:** ทำความสะอาดข้อมูลตัวอย่าง 10 แถวตามโจทย์ที่กำหนด |

## หมายเหตุสำหรับผู้สอน

1. **โปรเจกต์กลุ่ม** ควรประกาศโจทย์และ Dataset ตั้งแต่ครั้งที่ 8–9 เพื่อให้นักศึกษาเริ่มเก็บ/สำรวจข้อมูลคู่ขนานไปกับการเรียน โปรเจกต์ควรให้แต่ละกลุ่มเลือกธุรกิจที่สนใจ (หรือธุรกิจที่ตัวเองกำลังทำจริงในวิชาอื่น) เพื่อเชื่อมโยงกับหลักสูตรการสร้างเจ้าของธุรกิจ

2. **การจัดเวลา** แต่ละคาบ 150 นาที แนะนำแบ่งเป็นบรรยาย 50–60 นาที พัก 10 นาที และปฏิบัติจริง 70–80 นาที + Quiz 10–15 นาที เพื่อให้ทันเนื้อหาและได้ลงมือทำ

3. **ชุดข้อมูลตัวอย่าง** ทุกคาบควรใช้ชุดข้อมูลที่ใกล้เคียงกับธุรกิจจริง (ยอดขาย, ข้อมูลลูกค้า, แคมเปญ) และควรใช้ชุดข้อมูลต่อเนื่องกันหลายคาบ (เช่น ชุดข้อมูลร้านค้า E-commerce ใช้ตั้งแต่คาบ 5–12) เพื่อให้เห็นภาพรวมกระบวนการ Data Science ตั้งแต่ต้นจนจบ **ชุดข้อมูลควรไม่ซ้ำกับวิชา Data Analytics for Business** เพื่อให้นักศึกษาได้ประสบการณ์กับข้อมูลที่หลากหลาย

4. **Quiz แนะนำให้เป็นแบบสถานการณ์ (Scenario-based)** มากกว่าการคำนวณหรือสูตร เพื่อวัด "การตีความ" และ "การนำไปใช้" ซึ่งตรงกับเป้าหมายของกลุ่มผู้เรียนที่เป็นเจ้าของธุรกิจ

5. **ความสัมพันธ์กับวิชา Data Analytics for Business**: แม้ทั้งสองวิชาใช้ Excel เป็นเครื่องมือหลักเหมือนกัน แต่จุดเน้นต่างกัน — วิชา Data Analytics เน้น "เทคนิคการวิเคราะห์ข้อมูลเชิงการตลาด" (PivotTable เชิงลึก, RFM Analysis, Marketing Metrics, A/B Testing) ส่วนวิชานี้เน้น "กระบวนการคิดและกระบวนการทำ Data Science ทั้งวงจร" (Data Thinking, การตั้งสมมติฐาน, EDA, สถิติพื้นฐาน, การพยากรณ์, AI/ML เบื้องต้น, Data Storytelling) ควรสื่อสารกับอาจารย์ผู้สอนวิชา Data Analytics เพื่อไม่ให้ตัวอย่างและ Dataset ซ้ำกัน

6. **ฟังก์ชัน Excel ที่ซ้ำกันกับวิชา Data Analytics** (เช่น PivotTable, VLOOKUP, IF): วิชานี้ใช้ฟังก์ชันเหล่านี้เป็น "เครื่องมือ" เพื่อตอบคำถาม Data Science แทนที่จะสอนเป็นหัวข้อหลัก หากนักศึกษาเรียนทั้งสองวิชาพร้อมกัน จะได้ฝึกใช้ฟังก์ชันเหล่านี้ซ้ำจากมุมมองที่ต่างกัน ซึ่งจะช่วยให้เกิดความชำนาญมากยิ่งขึ้น

7. **เครื่องมือ AI** ในคาบที่ 11 ควรเตรียมแผนสำรอง (Backup Plan) กรณีที่ AI Tools มีการเปลี่ยนแปลง Interface หรือนโยบาย ควรเตรียมตัวอย่างภาพหน้าจอ (Screenshot) ไว้ด้วย

8. **เวอร์ชัน Excel**: แนะนำให้ใช้ Microsoft 365 (Excel for Microsoft 365) หรือ Excel 2021 ขึ้นไป เพื่อให้รองรับฟังก์ชันใหม่ เช่น XLOOKUP, Dynamic Arrays, Box & Whisker Chart หากนักศึกษาใช้เวอร์ชันเก่ากว่า ให้ใช้ VLOOKUP แทน XLOOKUP ได้

### ข้อตกลงร่วมกันสำหรับการเรียน (On-site ณ มหาวิทยาลัยศรีปทุม)

- ส่งงานให้ครบและตรงเวลาที่กำหนด เมื่อมีการนัดหมาย
- หากไม่สามารถเข้าเรียนได้ไม่ว่ากรณีใด ให้แจ้งอาจารย์ทราบและทำการลาให้เรียบร้อย
- เข้าเรียนสายเกิน 15 นาทีหลังเริ่มสอน ถือว่า "สาย" แต่ยังเข้าเรียนได้ — มีผลต่อคะแนนจิตพิสัยและการตัดเกรด
- ไม่ปัดคะแนนขึ้นสำหรับนักศึกษาที่ขาดความรับผิดชอบ
- การตัดสินจากอาจารย์ผู้สอนถือเป็นที่สิ้นสุด

> **หมายเหตุ:** กรณีเกิดความไม่ปกติในสถานการณ์ต่างๆ หรืออาจารย์ติดภารกิจ จะมีการแจ้งให้ทราบล่วงหน้า และอาจพิจารณาจัดการเรียนการสอนออนไลน์ หรือมอบหมายงานทดแทน กรณีอื่นๆ ให้เป็นไปตามประกาศของมหาวิทยาลัยศรีปทุม
