# **คำอธิบายรายวิชา**

รายวิชานี้ออกแบบมาสำหรับนักศึกษาที่ไม่มีพื้นฐานด้านเทคโนโลยีหรือข้อมูลมาก่อน มุ่งเน้นการสร้าง **กระบวนการคิดแบบนักวิทยาการข้อมูล (Data Thinking)** ให้กับเจ้าของธุรกิจยุคใหม่ ผู้เรียนจะได้เรียนรู้วิธีการตั้งคำถามทางธุรกิจอย่างเป็นระบบ การตั้งสมมติฐาน การเก็บและจัดเตรียมข้อมูลเบื้องต้นด้วย Microsoft Excel และการใช้ **AI Chat (ChatGPT / Gemini / Claude)** เป็นผู้ช่วยในการวิเคราะห์ข้อมูล สรุป Insight การค้นหาแนวโน้ม และการพยากรณ์เบื้องต้น

เนื้อหาครอบคลุมตั้งแต่ความเข้าใจพื้นฐานของกระบวนการ Data Science การจำแนกประเภทข้อมูลและแหล่งข้อมูลทางธุรกิจ สถิติพื้นฐานสำหรับการตัดสินใจ การอ่านและตีความผลข้อมูลด้วยภาพ (Data Visualization) เทคนิคการสั่งงาน AI (Prompt Engineering for Data Analysis) การวิเคราะห์ความสัมพันธ์ การพยากรณ์ยอดขาย การแบ่งกลุ่มลูกค้า ไปจนถึงการสื่อสารผลลัพธ์ข้อมูลอย่างทรงพลัง (Data Storytelling) และจริยธรรมในการใช้ AI โดยเน้นมุมมองของ **เจ้าของธุรกิจที่ใช้ AI เป็นเครื่องมือช่วยตัดสินใจ** โดยไม่จำเป็นต้องเขียนโค้ด

ผู้เรียนจะได้ฝึกปฏิบัติจริงผ่าน Workshop ทุกคาบเรียน โดยใช้กรณีศึกษาที่ใกล้เคียงกับธุรกิจจริง ปิดท้ายแต่ละคาบด้วย Quiz Game เพื่อทบทวนความเข้าใจ และจบรายวิชาด้วยการทำโปรเจกต์กลุ่มวิเคราะห์ข้อมูลธุรกิจจริง พร้อมนำเสนอผลลัพธ์ในคาบสุดท้าย

# **ผลลัพธ์การเรียนรู้ของรายวิชา**

เมื่อเรียนจบรายวิชานี้ นักศึกษาจะสามารถ:

1.  อธิบายแนวคิดและกระบวนการทำงานของ Data Science จำแนกประเภทข้อมูลทางธุรกิจ และเข้าใจบทบาทของข้อมูลในการตัดสินใจได้

2.  คิดเชิงข้อมูล (Data Thinking) — ตั้งคำถามทางธุรกิจอย่างเป็นระบบ ตั้งสมมติฐานที่ทดสอบได้ และวางแผนการเก็บข้อมูลได้อย่างเหมาะสม

3.  เก็บ จัดการ และทำความสะอาดข้อมูลเบื้องต้นด้วย Microsoft Excel ให้อยู่ในโครงสร้างที่พร้อมสำหรับการวิเคราะห์ได้

4.  ใช้ AI Chat เป็นผู้ช่วยวิเคราะห์ข้อมูล — เขียนคำสั่ง (Prompt) อย่างมีประสิทธิภาพ ตีความผลลัพธ์ ตรวจสอบความถูกต้อง และแปลง Insight เป็นการตัดสินใจทางธุรกิจได้

5.  สื่อสารผลการวิเคราะห์ข้อมูล (Data Storytelling) และนำเสนอข้อเสนอแนะเชิงธุรกิจจากข้อมูลจริงในรูปแบบโปรเจกต์กลุ่มได้อย่างมืออาชีพ

# **โครงสร้างรายวิชา (ภาพรวม)**

| **Module** | **ครั้งที่** | **หัวข้อหลัก** |
|----|----|----|
| **1. Data Thinking: คิดแบบนักวิทยาการข้อมูล** | 1–3 | ความหมายของ Data Science, กระบวนการคิดเชิงข้อมูล, การตั้งคำถามและสมมติฐาน, แหล่งข้อมูลธุรกิจ |
| **2. เตรียมข้อมูลให้พร้อมใช้งาน** | 4–5 | โครงสร้าง Tidy Data, การนำเข้าข้อมูล, Data Cleaning ด้วย Excel |

# **เครื่องมือหลักที่ใช้ในการเรียน**

- **Microsoft Excel** — ใช้ในการจัดเก็บ จัดโครงสร้างข้อมูล (Tidy Data), ทำความสะอาดข้อมูล (Data Cleaning), คำนวณสถิติพื้นฐาน, สร้างกราฟเบื้องต้น และตรวจสอบความถูกต้องของข้อมูล
- **AI Chat (ChatGPT / Gemini / Claude)** — ใช้เป็นผู้ช่วยหลักในการวิเคราะห์ข้อมูล, ค้นหา Insight, แนะนำกราฟ, พยากรณ์แนวโน้ม, แบ่งกลุ่มลูกค้า และช่วยร่างเนื้อหานำเสนอ
- **Kahoot! / Quizizz** — ใช้สำหรับ Quiz Game ท้ายคาบ เพื่อทบทวนความรู้และเก็บคะแนนสะสมแบบ Interactive
- **Microsoft PowerPoint** — ใช้ในการจัดทำสไลด์และนำเสนอ Data Storytelling สำหรับโปรเจกต์กลุ่ม

# **หมายเหตุสำหรับผู้สอน**

- โปรเจกต์กลุ่มควรประกาศโจทย์และเกณฑ์การประเมินตั้งแต่ครั้งที่ 8–9 เพื่อให้นักศึกษาเริ่มตั้งคำถามและรวบรวมข้อมูลควบคู่ไปกับเนื้อหาใน Module 4

- แต่ละคาบ 150 นาที (2.5 ชั่วโมง) จัดสรรเวลาเป็น บรรยาย 50 นาที, พัก 10 นาที, Workshop ปฏิบัติการ 70 นาที และ Quiz Game + สรุป 20 นาที

- ทุกคาบควรใช้ชุดข้อมูลตัวอย่างที่ใกล้เคียงกับธุรกิจจริง (ยอดขาย, แคมเปญ, ลูกค้า) และแนะนำให้ใช้ชุดข้อมูลต่อเนื่องกันหลายคาบเพื่อเห็นภาพกระบวนการตั้งแต่ต้นจนจบ โดยไม่ซ้ำซ้อนกับชุดข้อมูลในวิชา Data Analytics for Business

- การใช้ AI Chat ควรเน้นย้ำเรื่อง **Critical Thinking และการตรวจสอบความถูกต้อง (Fact-checking)** ทุกครั้ง ฝึกให้นักศึกษาไม่เชื่อผลลัพธ์จาก AI โดยทันที แต่ต้องมีเหตุผลและข้อมูลรองรับ

- Quiz Game ท้ายคาบเน้นการวัดความเข้าใจเชิงสถานการณ์ (Scenario-based) และการตัดสินใจ มากกว่าการจำสูตร เพื่อให้สอดคล้องกับเป้าหมายของกลุ่มผู้เรียนที่เป็นเจ้าของธุรกิจ

# **ผู้สอนและข้อตกลงในการเรียน**

## **ข้อมูลผู้สอน**

อาจารย์สุรชัย โกยสันติสุข

## **ข้อตกลงร่วมกันสำหรับการเรียน (On-site ณ มหาวิทยาลัยศรีปทุม)**

- ส่งงานให้ครบและตรงเวลาที่กำหนด เมื่อมีการนัดหมาย

- หากไม่สามารถเข้าเรียนได้ไม่ว่ากรณีใด ให้แจ้งอาจารย์ทราบและทำการลาให้เรียบร้อย

- เข้าเรียนสายเกิน 15 นาทีหลังเริ่มสอน ถือว่า “สาย” แต่ยังเข้าเรียนได้ — มีผลต่อคะแนนจิตพิสัยและการตัดเกรด

- ไม่ปัดคะแนนขึ้นสำหรับนักศึกษาที่ขาดความรับผิดชอบ

- การตัดสินจากอาจารย์ผู้สอนถือเป็นที่สิ้นสุด

หมายเหตุ: กรณีเกิดความไม่ปกติในสถานการณ์ต่างๆ หรืออาจารย์ติดภารกิจ จะมีการแจ้งให้ทราบล่วงหน้า และอาจพิจารณาจัดการเรียนการสอนออนไลน์ หรือมอบหมายงานทดแทน กรณีอื่นๆ ให้เป็นไปตามประกาศของมหาวิทยาลัยศรีปทุม
