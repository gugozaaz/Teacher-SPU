Analytics Mindset

1. รวดเร็ว & ทันเวลา

กฎพื้นฐานของการเขียนสูตรใน Google Sheets

เข้าใจโครงสร้างไวยากรณ์ (Syntax) ก่อนเริ่มกดเครื่องหมายเท่ากับ
Syntax 101

1. ต้องขึ้นต้นด้วย '=' เสมอ

หากไม่ใส่เครื่องหมายเท่ากับ ชีตจะมองสิ่งที่คุณพิมพ์เป็นเพียงข้อความธรรมดา (Text) ไม่ใช่คำสั่งคำนวณ

SUM(V2:V1001) ← กลายเป็นข้อความ!
=SUM(V2:V1001) ← สูตรคำนวณถูกต้อง

2. การอ้างอิงช่วงเซลล์ (Cell Range)

ใช้เครื่องหมายโคลอน : เพื่อบอกจุดเริ่มต้นถึงจุดสิ้นสุดของช่วงข้อมูล

V2:V1001 ← คอลัมน์ V ตั้งแต่แถว 2 ถึง 1001
V2:V ← คอลัมน์ V ตั้งแต่แถว 2 จนถึงแถวสุดท้าย
มือโปรแนะนำ: ใส่เครื่องหมาย $ เช่น $V$2:$V$1001 (Absolute Reference) เพื่อล็อคตำแหน่งเซลล์ไม่ให้เลื่อน เมื่อเราต้องการคัดลอก (Copy-Paste) สูตรไปยังเซลล์อื่น
กฎเหล็ก: ชื่อฟังก์ชันใน Sheets พิมพ์ตัวพิมพ์เล็กหรือใหญ่ก็ได้ แต่ วงเล็บเปิด-ปิด ต้องจับคู่ครบเสมอ
[Slide 6 Notes]: - ปูพื้นฐาน syntax ให้มั่นคง - นักศึกษาที่ไม่เคยแตะ Excel มักลืมเครื่องหมายเท่ากับ หรือวงเล็บเปิดปิดไม่ครบ

สูตรที่ 1: SUM — รวมทุกสิ่งทุกอย่างในธุรกิจ

หาผลรวมตัวเลขในชั่วพริบตา ไม่ต้องจิ้มบวกทีละเซลล์
Formula 1/4
=SUM(range)
// ตัวอย่าง: รวมยอดขายสุทธิทั้งหมดในคอลัมน์ V
=SUM(V2:V1001)

ผลลัพธ์จาก Dataset จริง:

฿126,375.75
ยอดขายสุทธิรวม (Total Net Sales) จาก 1,000 รายการสินค้า (575 บิล)

เจ้าของธุรกิจใช้ SUM กับอะไรบ้าง?

  • ยอดขายรวม (Total Revenue): =SUM(V2:V1001) ได้ ฿126,375.75
  • ส่วนลดรวมที่ให้ลูกค้า (Total Discounts): =SUM(U2:U1001) รวมได้ ฿9,949.25
  • จำนวนชิ้นที่ขายได้รวม (Total Units): =SUM(S2:S1001) รวมได้ 1,168 ชิ้น
  • แต้มสะสม CRM ที่แจกไป: =SUM(X2:X1001) เพื่อบริหารแต้มคงค้าง
ข้อควรระวัง: SUM จะข้ามช่องที่เป็นข้อความ (Text) หรือช่องว่างโดยอัตโนมัติ แต่ถ้าเผลอมีตัวเลขที่ถูกจัดรูปแบบเป็น Text (มีเครื่องหมาย ' นำหน้า) ตัวเลขนั้นจะไม่ถูกนำมารวม!
[Slide 7 Notes]: - แสดงตัวเลขจริงจาก Dataset 1,000 แถว: ยอดขายรวม 151,947.75 บาท - เชื่อมโยงว่าทำไมต้องรวมทั้งยอดขายและส่วนลด

สูตรที่ 2: AVERAGE — หาค่าเฉลี่ยและ AOV หัวใจของคาเฟ่

Average Order Value: ตัวชี้วัดสำคัญที่สุดในการวัดขนาดตะกร้าของลูกค้า
Formula 2/4
=AVERAGE(range)
// ตัวอย่าง: หายอดขายเฉลี่ยต่อบิล
=AVERAGE(V2:V1001)

ผลลัพธ์ค่าเฉลี่ยจาก Dataset:

฿126.38 / รายการสินค้า
AOV = ฿219.78 / บิลคำสั่งซื้อ
(เพราะ 1 บิลมีการสั่งเฉลี่ย 1.74 รายการ ดันยอดต่อบิลทะลุ 219 บาท!)

Business Value ของ AOV สำหรับผู้ประกอบการ

ถ้าร้านอยากได้ยอดขายเพิ่มขึ้น 20% คุณมี 2 ทางเลือก:
1. หาลูกค้าใหม่เพิ่ม (ค่าโฆษณาสูงมาก)
2. ดัน AOV ให้สูงขึ้น (Cross-selling เชียร์ขนมคู่กาแฟ ทำให้ 1 บิลมี 2 ชิ้นขึ้นไป)

คะแนนความพึงพอใจเฉลี่ย: =AVERAGE(Y2:Y1001) ได้ 4.49 ดาว สะท้อนความสุขของลูกค้า
ระวัง Outliers: ถ้ามีออเดอร์จัดเลี้ยง 1 บิลมูลค่า 10,000 บาท ค่าเฉลี่ย AVERAGE จะพุ่งสูงจนหลอกตาได้ (ใน Session ถัดไปเราจะเรียนรู้เรื่อง Median เพื่อตรวจสอบคู่กัน)
[Slide 8 Notes]: - ชี้ให้เห็นว่า AOV (Average Order Value) คือ KPI พระเอกของร้านอาหารและคาเฟ่ - กาแฟแก้วละ 80 บาท แต่ AOV ออกมา 152 บาท เพราะลูกค้ามักสั่งขนมเพิ่มหรือสั่ง 2 แก้ว

สูตรที่ 3: COUNT vs COUNTA — นับจำนวนอย่างไรไม่ให้พลาด?

การนับปริมาณธุรกรรม (Volume) และการตรวจสอบความสมบูรณ์ของข้อมูล
Formula 3/4

COUNT — นับเฉพาะ "ตัวเลข"

=COUNT(V2:V1001)

• นับเฉพาะเซลล์ที่มีค่าเป็นตัวเลข (Numbers)
• ข้ามช่องว่าง และข้ามข้อความ
• ใช้ตรวจสอบว่ามียอดเงินที่ถูกบันทึกสำเร็จกี่รายการ (ได้ 1,000 รายการ)

COUNTA — นับ "ทุกช่องที่ไม่ว่าง" (All)

=COUNTA(H2:H1001)

• ตัว 'A' ย่อมาจาก All / Any
• นับทั้งข้อความ ตัวเลข สัญลักษณ์ หรือวันที่
• ใช้สำหรับนับชื่อลูกค้า (Customer_Name) หรือรหัสธุรกรรมที่ไม่ใช่ตัวเลขบริสุทธิ์

ข้อผิดพลาดคลาสสิก: ถ้าคุณใช้ =COUNT(H2:H1001) ในการนับคอลัมน์ชื่อลูกค้า (Customer_Name) ผลลัพธ์ที่ได้จะเป็น 0 ทันที! เพราะชื่อคนเป็นข้อความ ต้องใช้ COUNTA เท่านั้น
ท่องจำง่ายๆ: COUNT = นับเฉพาะเลข | COUNTA = นับทุกช่องที่ไม่ว่างเปล่า
[Slide 9 Notes]: - เน้นย้ำข้อผิดพลาดที่พบบ่อยมากในเด็กปี 1 คือเอา COUNT ไปนับคอลัมน์ชื่อคนแล้วได้ 0 - แยกแยะ COUNT vs COUNTA ให้ชัดเจน

สูตรที่ 4: SUMIF — รวมยอดขายแบบมีเงื่อนไข

ก้าวแรกสู่การวิเคราะห์แบบแบ่งกลุ่ม (Segmentation) เจาะจงสิ่งที่ต้องการรู้
Formula 4/4
=SUMIF(range, criterion, [sum_range])
// 1. range: ช่วงข้อมูลที่ใช้ตรวจเงื่อนไข (เช่น คอลัมน์สาขา L2:L1001)
// 2. criterion: เงื่อนไขที่ต้องการกรอง (เช่น "สาขาสยามสแควร์")
// 3. sum_range: ช่วงข้อมูลตัวเลขที่ต้องการให้นำมาบวกกัน (เช่น ยอดขาย V2:V1001)

ตัวอย่าง 1: ยอดขายเฉพาะสาขาสยาม

=SUMIF(L2:L1001, "สาขาสยามสแควร์", V2:V1001)

ได้ผลลัพธ์: ฿47,949.75
(คิดเป็น 37.9% ของยอดขายทั้งบริษัท!)

ตัวอย่าง 2: ยอดขายจากลูกค้า Platinum

=SUMIF(I2:I1001, "Platinum", V2:V1001)

ได้ผลลัพธ์: ฿29,652.25
(พลังของ Member CRM ซื้อสม่ำเสมอทั้งไตรมาส)

ข้อสังเกต: ข้อความที่เป็นเงื่อนไขต้องครอบด้วยเครื่องหมายอัญประกาศคู่ "..." เสมอ หรือจะคลิกชี้ไปยังเซลล์ที่มีข้อความนั้นอยู่ก็ได้ เช่น =SUMIF(L2:L1001, A2, V2:V1001)

Power Combo

ฟังก์ชันสถิติพื้นฐาน: MIN, MAX & MEDIAN

สำรวจขอบเขตยอดขาย ราคา และค้นหาค่ากลางที่แท้จริงไม่ถูก Outlier หลอก
Statistics

MIN & MAX — ขอบเขตต่ำสุดและสูงสุด

=MIN(V2:V1001)  →  ฿55.25
=MAX(V2:V1001)  →  ฿780.00

• MIN: หายอดขาย/ราคาต่ำสุด → กาแฟ/เบเกอรี่หลังหักส่วนลดสมาชิก
• MAX: หาสินค้า Hero / เมล็ดกาแฟ Special Roast / สินค้าของสะสม
• Business Value: ใช้ทำ Sanity Check ตรวจสอบว่ามีข้อมูลผิดปกติหรือไม่ (เช่น ยอดขายติดลบ หรือบิล 0 บาทที่พนักงานลืมคิดเงิน)

MEDIAN — ค่ามัธยฐาน เกราะป้องกัน Outlier

=MEDIAN(V2:V1001)  →  ฿95.00
เทียบกับ =AVERAGE(V2:V1001) ที่ได้ ฿126.38 (ต่างกันถึง ฿31.38!)

• MEDIAN: คือค่ากึ่งกลางของข้อมูลเมื่อนำมาเรียงจากน้อยไปมาก
• ทำไม AVERAGE ถึงสูงกว่า?: เพราะมีสินค้าราคาสูง (MAX ฿780) ดึงค่าเฉลี่ยขึ้นไป
• Insight: ลูกค้ามากกว่าครึ่งหนึ่งจ่ายจริงไม่เกิน 95 บาท ต่อรายการ!

กฎเหล็กของเจ้าของธุรกิจ: ในการวิเคราะห์ยอดขายและพฤติกรรมลูกค้า อย่าดูแค่ AVERAGE เพียงอย่างเดียว! ให้ดู MEDIAN และ MIN / MAX ควบคู่เสมอเพื่อเห็นภาพความจริงที่ไม่ถูกข้อมูลสุดโต่ง (Outliers) บิดเบือน
[Slide 12 Notes]: - อธิบาย MIN, MAX ช่วยเช็คขอบเขตราคาและตรวจจับความผิดปกติของข้อมูล - ชี้ให้เห็นว่า AVERAGE โดนค่า MAX (780 บาท) ดึงขึ้นไปเป็น 126.38 บาท แต่มัธยฐาน MEDIAN อยู่ที่ 95 บาท - นี่คือสิ่งที่เจ้าของธุรกิจต้องเข้าใจเพื่อไม่ให้ตัดสินใจผิดพลาด

ฟังก์ชันยอดฮิตในงานธุรกิจ: IF, UNIQUE & ROUND

ติดสปีดการทำงาน: ตรรกะตัดสินใจ ดึงรายการไม่ซ้ำ และจัดระเบียบตัวเลข
Daily Essentials

IF — ตรรกะตัดสินใจ

=IF(V2>=250, "Big Ticket", "Standard")

• ไวยากรณ์: =IF(เงื่อนไข, จริง, เท็จ)
• ตัวอย่าง: คัดแยกรายการยอดสั่งซื้อเกิน ฿250 ขึ้นไปเป็นบิลใหญ่ (พบ 87 รายการ)
• ใช้สร้างป้าย Tag ลูกค้า VIP หรือให้คะแนนโปรโมชั่นอัตโนมัติ

UNIQUE — ดึงค่าไม่ซ้ำ

=UNIQUE(N2:N1001)

• ไวยากรณ์: =UNIQUE(ช่วงข้อมูล)
• ตัวอย่าง: ดึงหมวดสินค้าจาก 1,000 แถว → Coffee, Bakery, Non-Coffee, Merchandise
• ช่วยสำรวจมิติของตารางข้อมูลได้อย่างรวดเร็วใน 1 วินาที โดยไม่ต้องเลื่อนหา

ROUND — ปัดเศษตัวเลข

=ROUND(AVERAGE(V2:V1001), 2)

• ไวยากรณ์: =ROUND(ตัวเลข, [ทศนิยม])
• ตัวอย่าง: ปัดเศษทศนิยมให้เรียบร้อย หรือใช้ =ROUND(..., 0) เป็น ฿126
• ช่วยให้รายงานและตัวเลขแดชบอร์ดอ่านง่าย สะอาดตา ดูเป็นมืออาชีพ

กล่องเครื่องมือครบครัน (Spreadsheet Toolbox): เรามีครบทั้ง SUM, AVERAGE, COUNT, COUNTA, SUMIF, COUNTIF, MIN, MAX, MEDIAN, IF, UNIQUE, ROUND พร้อมรับมือการคำนวณพื้นฐานในธุรกิจได้ทุกรูปแบบ!
[Slide 13 Notes]: - แนะนำ 3 ฟังก์ชันที่คนทำงานชีตต้องใช้ทุกวัน: IF สำหรับตัดสินใจ, UNIQUE สำหรับดูภาพรวมค่าที่ไม่ซ้ำ, และ ROUND สำหรับปัดเศษ - เน้นย้ำว่าเมื่อเรารู้จักฟังก์ชันเหล่านี้แล้ว เราจะเริ่มเห็นว่าถ้าคำถามซับซ้อนขึ้น การเขียนสูตรทีละช่องจะเริ่มไม่ไหว

จุดที่สูตรมือเริ่ม "ตัน": เมื่อโจทย์ธุรกิจหลายมิติ

ถ้าผู้บริหารหรือเจ้าของแบรนด์เริ่มถามคำถามที่ซับซ้อนขึ้นเรื่อยๆ...
Formula Trap

คำถามจริงจากผู้บริหารร้านกาแฟ:

"ช่วยสรุปยอดขายแยกตาม สาขา (4 สาขา) ตัดกับ เกรดสมาชิก (5 ระดับ) และดูเฉพาะ หมวดเครื่องดื่มกาแฟ ใน ช่วงบ่าย ให้หน่อย... ขอภายใน 5 นาทีนะ!"

ถ้าคุณใช้สูตรมือ (Formula Approach):

• คุณต้องสร้างตาราง 4 x 5 = 20 ช่อง
• ต้องเขียนสูตร SUMIFS ซ้อน 4 เงื่อนไขในทุกช่อง
• ตัวอย่างสูตร 1 ช่อง:

=SUMIFS(V:V, L:L, "สยามสแควร์", I:I, "Platinum", N:N, "Coffee", D:D, "บ่าย*")
→ ต้องก๊อปปี้สูตร 20 ครั้ง ถ้าพิมพ์ผิด 1 ตัวอักษร ตัวเลขพังทันที!

ถ้าคุณใช้ Pivot Table:

• คลิกเมนู Insert > Pivot table
• ลาก Branch ใส่ Rows
• ลาก Tier ใส่ Columns
• ลาก Net_Amount ใส่ Values
• ใส่ Filter Category = Coffee, Slot = บ่าย

→ เสร็จสมบูรณ์ใน 15 วินาที ไร้ข้อผิดพลาด 100%!
Productivity Gap: เขียนสูตรมือใช้เวลา 25 นาที (เสี่ยงพัง) vs Pivot Table 15 วินาที สลับมุมมองได้ทันที
[Slide 14 Notes]: - จุดเปลี่ยนสำคัญของคาบเรียน: ชี้ให้เห็น Pain point ของการเขียนสูตรมือ - ทำไมต้องมี Pivot Table? เพราะธุรกิจจริงไม่เคยตัดข้อมูลแค่มิติเดียว

มวยถูกคู่: Formulas vs Pivot Table

เครื่องมือไหนเหมาะกับงานอะไร? เลือกใช้ให้ถูกจังหวะแบบมืออาชีพ
Decision Guide
คุณลักษณะ การเขียนสูตร (Formulas) Pivot Table
ความเร็วในการตั้งต้น เร็วถ้าคำนวณตัวเลขเดี่ยว 1-2 ช่อง เร็วมากในการสรุปข้อมูลก้อนใหญ่หลายมิติ
การสลับมุมมอง (Slice & Dice) ยาก ต้องรื้อพิมพ์สูตรและโครงตารางใหม่ ลาก-วาง (Drag & Drop) สลับได้ใน 3 วินาที
ความเสี่ยง Human Error สูง (สะกดเงื่อนไขผิด, ล็อค Dollar Sign ผิด) ต่ำมาก (ระบบดึงค่าที่มีจริงมาจัดกลุ่มอัตโนมัติ)
การขยายตัวของข้อมูลใหม่ ถ้ามีสาขาใหม่ ต้องมาแทรกแถวเขียนสูตรเพิ่ม อัปเดตอัตโนมัติทันทีที่มีข้อมูลใหม่เพิ่มเข้ามา
กรณีใช้งานที่เหมาะสมที่สุด ทำช่องสรุป KPI เล็กๆ ใน Dashboard ค้นหา Insight, จัดทำรายงานผู้บริหาร, CRM
สรุปหลักการเลือกใช้: ถ้าต้องการตัวเลขสรุป "ช่องเดียวจบ" เช่น ยอดขายรวมทั้งร้าน → ใช้ SUM แต่ถ้าต้องการ "สำรวจข้อมูลหลายมิติเพื่อหาคำตอบทางธุรกิจ" → ใช้ Pivot Table
[Slide 15 Notes]: - ตารางเปรียบเทียบชัดเจน - ไม่ได้บอกว่าสูตรไม่ดี แต่บอกว่าสูตรกับ Pivot ทำหน้าที่คนละอย่างกันในชีวิตจริง

ถอดรหัส 4 กล่องมหัศจรรย์ของ Pivot Table

เข้าใจ 4 องค์ประกอบนี้ คุณจะวิเคราะห์ข้อมูลใดๆ ในโลกธุรกิจได้ทั้งหมด
Core Architecture

1. แถว (Rows)

แกนแนวตั้ง

สิ่งที่คุณต้องการ "แยกดูเป็นบรรทัดๆ" เช่น รายชื่อสาขา, ชื่อหมวดหมู่สินค้า, หรือระดับสมาชิก (Platinum, Gold, Silver)

2. คอลัมน์ (Columns)

แกนแนวนอน

มิติที่ต้องการ "ตัดขวางเปรียบเทียบ" เช่น ช่องทางการขาย (Dine-in, Takeaway, Delivery) หรือช่วงเวลา (เช้า, เที่ยง, บ่าย)

3. ค่า (Values)

ตัวเลขคำนวณ

ตัวเลขที่คุณต้องการให้ "คำนวณสรุป" เช่น ผลรวมยอดขาย (SUM of Net_Amount), ยอดเฉลี่ย (AVERAGE), หรือนับจำนวนบิล (COUNT)

4. ตัวกรอง (Filters)

เจาะจงเฉพาะกลุ่ม

กรองข้อมูลเฉพาะกลุ่มที่สนใจ เช่น เลือกดูเฉพาะ "วันหยุดสุดสัปดาห์ (Weekend)" หรือดูเฉพาะลูกค้าเพศหญิง

กุญแจสำคัญ: คิดในใจเสมอว่า "อยากให้แถวแสดงอะไร? อยากให้คอลัมน์ตัดด้วยอะไร? และอยากคำนวณตัวเลขไหน?" แล้วลากฟิลด์ลงใน 4 กล่องนี้
[Slide 16 Notes]: - โฟกัส 4 กล่อง: Rows, Columns, Values, Filters - ย้ำว่า Values คือกล่องเดียวที่ใส่ตัวเลขเพื่อคำนวณ ส่วน Rows/Columns คือการจัดหมวดหมู่

ขั้นตอนสร้าง Pivot Table ใน Google Sheets

3 ขั้นตอนง่ายๆ ที่ใครก็ทำตามได้ทันทีบนหน้าจอ
3 Simple Steps

Step 1: ไฮไลท์ข้อมูล

คลิกที่เซลล์ใดเซลล์หนึ่งในตาราง แล้วกดคีย์ลัด Ctrl + A (หรือ Cmd + A บน Mac) เพื่อเลือกข้อมูลทั้ง 1,000 แถว

Step 2: เลือกคำสั่งแทรก

ไปที่เมนูบาร์ด้านบน คลิก แทรก (Insert) > เลือก ตารางเดือย (Pivot table) > เลือกสร้างใน "แผ่นงานใหม่ (New sheet)"

Step 3: ตั้งค่าใน Editor

แถบ Pivot table editor จะเปิดขึ้นมาทางขวา กดปุ่ม Add หรือลากชื่อคอลัมน์ลงในช่อง Rows, Columns และ Values ตามต้องการ

ทำไมต้องสร้างใน New sheet? เพื่อแยกแผ่นงานวิเคราะห์ออกจากชีตข้อมูลดิบอย่างเด็ดขาด ตามกฎ "Don't Touch Raw Data" ที่เราเน้นย้ำมาตลอด ป้องกันไม่ให้เผลอไปลบหรือแก้ไขข้อมูลต้นฉบับ
พร้อมแล้ว: มาลองลงมือวิเคราะห์เคสธุรกิจ CRM จริงกันใน 3 สไลด์ถัดไป!
[Slide 17 Notes]: - แนะนำคีย์ลัด Ctrl + A - ชี้แจงว่าเมนูภาษาไทยใช้คำว่า "ตารางเดือย" (Pivot table)

ปรับแต่งขั้นสูง: Filters และ Slicers

เปลี่ยน Pivot Table ให้กลายเป็น Interactive Dashboard ขนาดย่อม
Interactive Tools

1. Built-in Pivot Filters

ในช่อง Filters ของ Pivot table editor คุณสามารถกรองข้อมูลได้ 2 รูปแบบ:
• Filter by Values: ติ๊กเลือกเฉพาะรายการที่ต้องการ (เช่น ติ๊กเลือกเฉพาะเพศหญิง)
• Filter by Condition: กรองด้วยสูตร เช่น ยอดขายมากกว่า 200 บาท หรือวันที่อยู่ในเดือนมีนาคม

2. Slicers (ตัวควบคุมข้อมูลลอยตัว)

ไปที่เมนู ข้อมูล (Data) > เพิ่มตัวควบคุมข้อมูล (Add a slicer)
• สร้างปุ่มดรอปดาวน์ลอยอยู่เหนือตาราง เช่น ตัวเลือก "เลือกสาขา" หรือ "เลือกประเภทวัน"
• เมื่อคลิกเลือก ปุ่ม Slicer จะกรองตาราง Pivot Table ทุกตารางในชีตให้เปลี่ยนผลลัพธ์ตามทันที!

ทำไมเจ้าของธุรกิจต้องชอบ Slicers? เพราะคุณสามารถสร้างชีตสรุปยอดขายให้ผู้จัดการสาขาใช้ โดยผู้จัดการแค่กดคลิกเปลี่ยนชื่อสาขาใน Slicer ตารางทั้งหน้าก็เปลี่ยนเป็นข้อมูลสาขานั้นทันที ไม่ต้องสอนเขาเขียนสูตรแม้แต่นิดเดียว!
ประโยชน์สูงสุด: เปลี่ยนตารางสถิตินิ่งๆ ให้กลายเป็น ระบบรายงานที่โต้ตอบได้ (Interactive Report)
[Slide 21 Notes]: - แนะนำ Slicer ซึ่งเป็นฟีเจอร์ที่นักศึกษาชอบมาก - ช่วยให้เหมือนมี Dashboard ส่วนตัวโดยไม่ต้องเขียนโค้ด

Troubleshooting

1. ข้อผิดพลาด #REF! หรือ #VALUE!

สาเหตุ: ไปลบคอลัมน์ที่สูตรอ้างอิงอยู่ หรือเผลอเอาตัวเลขไปคูณกับเซลล์ที่มีข้อความ
วิธีแก้: กด Ctrl + Z เพื่อยกเลิก หรือตรวจสอบว่าเซลล์ในสูตรพิมพ์อ้างอิงถูกคอลัมน์หรือไม่

2. Pivot Table คำนวณเป็น 0 ทั้งตาราง

สาเหตุ: คอลัมน์ตัวเลขถูกมองเป็น Text (มักเกิดจากการ Import CSV ที่มีช่องว่างนำหน้า)
วิธีแก้: กลับไปที่ชีตข้อมูลดิบ ไฮไลท์คอลัมน์ แล้วเปลี่ยน Format เป็น Number (ตัวเลข)

3. ข้อมูลใหม่เพิ่มเข้ามา แต่ Pivot ไม่เปลี่ยน

สาเหตุ: Range ใน Pivot ระบุไว้จำกัด เช่น A1:Y1001 พอมีแถว 1002 เลยไม่ถูกนับ
วิธีแก้: แก้ไข Data Range เป็นแบบเปิดท้าย เช่น A1:Y เพื่อให้ครอบคลุมทุกแถวที่เพิ่มในอนาคต

4. สาขาหรือชื่อเดียวกัน ปรากฏซ้ำคนละแถว

สาเหตุ: ปัญหา Whitespace (เว้นวรรคส่วนเกิน) เช่น "สาขาอารีย์ " กับ "สาขาอารีย์"
วิธีแก้: ต้องใช้คำสั่ง Data Cleanup > Trim whitespace ตามที่เรียนใน Session 5
