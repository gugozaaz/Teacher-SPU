2 📝 Mission 2: Google Forms Live Architect (สร้างระบบดูดข้อมูลอัตโนมัติ)

เปิด forms.google.com แล้วสร้างแบบฟอร์มสั่งซื้อออนไลน์จริง โดยออกแบบ 5 คำถามสำคัญให้ได้ Tidy Data:

ข้อความคำถาม ชนิดคำถามใน Forms Required? การตั้ง Response Validation
1. วันที่ต้องการรับเค้ก จำเป็น
2. รสชาติเค้กหลัก จำเป็น
3. จำนวนที่สั่ง (ชิ้น/ปอนด์) จำเป็น
4. เบอร์โทรศัพท์ลูกค้า จำเป็น
5. ช่องทางชำระเงิน จำเป็น
3 📖 Mission 3: Data Dictionary Blueprint (ร่างพจนานุกรมข้อมูลธุรกิจ)

สร้างเอกสารอธิบายโครงสร้างและความหมายของทุกคอลัมน์ เพื่อส่งต่อให้ทีมงานและ AI ใช้งานได้อย่างแม่นยำ:

Column Name Description (ความหมาย) Data Type Allowed Values / Format Example
Timestamp เวลาที่ระบบบันทึกคำสั่งซื้อ DateTime YYYY-MM-DD HH:MM:SS 2026-03-01 10:14:22
Delivery_Date วันที่ลูกค้าต้องการรับสินค้า Date YYYY-MM-DD 2026-03-05
