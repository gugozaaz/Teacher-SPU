ข้อมูลสกปรกมาจากไหน?

  • Human Error: พนักงานพิมพ์ตกหล่น, เผลอกด Spacebar ท้ายชื่อ, กรอกเบอร์โทรผิดรูปแบบ
  • Multiple Channels: รวมข้อมูลจาก TikTok Shop, Shopee, หน้าร้าน POS แต่ละที่ตั้งชื่อสินค้าไม่เหมือนกัน

  • System Glitch: เน็ตหลุดขณะส่งฟอร์มทำให้มีแถวซ้ำ หรือส่งข้อมูลไม่ครบ

เสาหลักที่ 2: ผ่า 5 กายวิภาคข้อมูลสกปรก (5 Traps)

5 ปัญหาคลาสสิกที่พบในตารางยอดขายและฐานข้อมูลของธุรกิจไทย
5 Common Traps
Trap 1

ข้อมูลซ้ำซ้อน (Duplicates)

ออเดอร์เดียวกันถูกบันทึก 2 ครั้ง ทำให้ยอดขายพอง ยอดสต็อกหาย

Trap 2

ช่องว่างล่องหน & สะกดเพี้ยน

เผลอเคาะ Spacebar หน้า-หลัง หรือสะกดคนละแบบ Pivot รวมกลุ่มไม่ได้

Trap 3

ข้อมูลขาดหาย (Missing Values)

ปล่อยเซลล์ว่าง, ค่า NULL, ใส่เครื่องหมายขีด (-) โดยไม่แยกประเภท

Trap 4

วันที่และตัวเลขสับสน (Inconsistent Format)

บันทึก ว/ด/ป สลับ ด/ว/ป หรือมีเครื่องหมายลูกน้ำ/ตัวอักษรปนจนสูตร SUM ทำงานไม่ได้

Trap 5

ค่าผิดปกติ / ค่าหลุดโลก (Outliers)

ข้อมูลสุดโต่งที่เกิดจากพิมพ์ผิด เช่น อายุ 300 ปี, ราคาสินค้า -100 บาท ดึงค่าเฉลี่ยเพี้ยน

มาเจาะลึกอาการและวิธีรักษาของแต่ละ Trap ไปพร้อมกันทีละข้อ

Trap 1: ข้อมูลซ้ำซ้อน (Duplicate Records)

เมื่อแถวข้อมูลออเดอร์เดียวกันถูกบันทึกเบิ้ลโดยไม่รู้ตัว

หลักคิด: ก่อนรวมยอดขายทุกครั้ง ต้องตรวจสอบและลบแถวซ้ำออกเสมอ

ทางแก้ Trap 1: เมนู Data Cleanup → Remove Duplicates

วิธีลบแถวซ้ำอย่างปลอดภัยด้วยฟังก์ชันสำเร็จรูปใน Google Sheets
Tool Guide

3 สเต็ปง่ายๆ ลบข้อมูลซ้ำ

1. คลุมแถบข้อมูลทั้งหมด (หรือกด Ctrl + A)
2. ไปที่เมนูบาร์ด้านบน:
    Data (ข้อมูล) → Data cleanup → Remove duplicates
3. ติ๊กถูกที่ช่อง "Data has header row" (ข้อมูลมีแถวส่วนหัว)
4. เลือกว่าจะเช็คซ้ำทุกคอลัมน์ หรือเช็คเฉพาะคอลัมน์ Order ID แล้วกด Remove duplicates

ข้อควรระวังในการเลือกคอลัมน์!

• ถ้าติ๊ก "Select all columns": ระบบจะลบก็ต่อเมื่อ ทุกช่องในแถวนั้นเหมือนกันทุกตัวอักษร
• ถ้าติ๊กเฉพาะ "Order ID": หากเจอ Order ID ซ้ำ ระบบจะเก็บแถวแรกไว้ และลบแถวที่สองทันที

คำเตือน: หากมี 1 ออเดอร์ซื้อสินค้าหลายชิ้น อย่าติ๊กเฉพาะ Order ID เพราะจะลบสินค้าชิ้นอื่นทิ้ง!
Alternative Formula: สามารถใช้สูตร =UNIQUE(A2:D100) เพื่อดึงเฉพาะแถวที่ไม่ซ้ำไปวางในชีตใหม่ได้โดยไม่กระทบข้อมูลต้นฉบับ

" ชบา" ชบา มี Space ข้างหน้า (4 ตัว)

หายนะที่เกิดขึ้นกับธุรกิจ:
  • Pivot Table แยกแถว: สรุปยอดขายเสื้อ "ชบา" กลายเป็น 3 บรรทัด ยอดขายกระจายรวมยอดไม่ติด!
  • VLOOKUP ขึ้น #N/A: ค้นหารหัสสินค้าไม่เจอ เพราะรหัสในตารางมีเคาะเว้นวรรคแอบแฝง
  • Filter หลุด: กรองหาสาขา "สยาม" ไม่เจอสาขาที่มีช่องว่างข้างหน้า
การตรวจจับ: ใช้สูตร =LEN(A2) เพื่อดูความยาวตัวอักษรจริงว่าเกินกว่าที่ควรจะเป็นหรือไม่
กฎทอง: 1 เคาะของมนุษย์ คือ 1 รหัสลับของคอมพิวเตอร์เสมอ

ทางแก้ Trap 2: ฟังก์ชัน TRIM & เครื่องมือ Trim Whitespace

ตัดช่องว่างส่วนเกินออกอย่างหมดจดใน 1 วินาที
Cleanup Toolkit

วิธีที่ 1: เมนูอัตโนมัติ (Data Cleanup)

1. คลุมคอลัมน์ที่มีปัญหา (เช่น คอลัมน์ชื่อสินค้า)
2. ไปที่ Data → Data cleanup → Trim whitespace
3. ระบบจะตัดช่องว่างที่อยู่ ข้างหน้าสุด และ ข้างหลังสุด ของทุกเซลล์ทิ้งทันที

รวดเร็ว สะดวก ไม่ต้องเขียนสูตร

วิธีที่ 2: ฟังก์ชัน =TRIM()

ใช้สร้างคอลัมน์ใหม่เพื่อความสะอาดสมบูรณ์แบบ:
=TRIM(A2)

ความพิเศษของ =TRIM():

นอกจากตัดช่องว่างหน้า-หลังแล้ว ยัง ยุบช่องว่างตรงกลางที่เคาะเกิน 1 ครั้ง ให้เหลือเพียง 1 เคาะมาตรฐานโดยอัตโนมัติ!

ก่อน TRIM: "  เสื้อยืด    สีขาว  " (ความยาว 19 ตัวอักษร)
หลัง TRIM: "เสื้อยืด สีขาว" (เหลือช่องว่าง 1 เคาะตรงกลาง สะอาด 100%)

หมวดหมู่ สิ่งที่พนักงานกรอกมา ผลกระทบ
ไซส์เสื้อ "XL", "xl", "Xl", " เอ็กแอล" ระบบนับเป็น 4 ไซส์!

ชื่อสาขา "สยาม", "Siam", "สาขาสยาม" เทียบยอดสาขาลำบาก

ทำไมถึงเป็นปัญหาใหญ่?

คอมพิวเตอร์และระบบฐานข้อมูลไม่ได้มี "Common Sense" เหมือนมนุษย์ เมื่อตัวอักษรต่างกันแม้แต่ตัวเดียว หรือตัวพิมพ์เล็กต่างกับตัวพิมพ์ใหญ่ ระบบจะแยกเป็นคนละประเภททันที

มาตรฐานสากล: ต้องเลือกใช้ คำมาตรฐานคำเดียว (Standard Canonical Term) สำหรับค่าข้อมูลแต่ละความหมาย
หลักปฏิบัติ: ข้อมูลประเภทเดียวกัน ต้องสะกดเหมือนกันและใช้รูปแบบเดียวกันทั้งตาราง

ทางแก้ Text Formatting: ฟังก์ชันจัดฟอนต์ & Find & Replace

ปรับตัวพิมพ์ให้เท่ากัน และแก้คำสะกดผิดเป็นหมื่นแถวในคลิกเดียว
Text Tools

ฟังก์ชันปรับขนาดตัวพิมพ์สากล

• =UPPER(A2) : เปลี่ยนเป็นตัวพิมพ์ใหญ่ทั้งหมด เช่น xl → XL
• =LOWER(A2) : เปลี่ยนเป็นตัวพิมพ์เล็กทั้งหมด เช่น Gmail.COM → gmail.com
• =PROPER(A2) : ตัวพิมพ์ใหญ่นำหน้าคำ เช่น bangkok → Bangkok

Find & Replace ขั้นเทพ (Ctrl + H)

ใช้แก้คำสะกดผิดหรือเปลี่ยนชื่อเรียกเป็นกลุ่ม:

1. กด Ctrl + H (หรือเมนู Edit → Find and replace)
2. ช่อง Find: พิมพ์คำที่สะกดผิด (เช่น White)
3. ช่อง Replace with: พิมพ์คำมาตรฐาน (เช่น ขาว)
4. ติ๊กถูกที่ "Match entire cell contents" เพื่อป้องกันแทนที่ผิดคำ!
Pro Tip: ติ๊ก "Match entire cell contents" เสมอ! มิฉะนั้นหากค้นหาคำว่า "ขา" เพื่อแก้เป็น "ขาว" คำว่า "กางเกงขายาว" จะกลายเป็น "กางเกงขาวยาว" ทันที!

Trap 3: ข้อมูลขาดหาย (Missing Values / Null Data)

หลุมดำของตารางข้อมูล: เซลล์ว่าง, ค่า Null, และการกรอกเครื่องหมายกำกวม
Trap 3

ลักษณะของ Missing Data

รหัสลูกค้า ชื่อลูกค้า เบอร์โทร ยอดซื้อสะสม
CUST-001 คุณสมศักดิ์ 0812345678 4,500
CUST-002 คุณพรทิพย์ (ช่องว่าง) 1,200
CUST-003 คุณประเสริฐ - NULL
CUST-004 คุณดาริกา 0899998888 0
ความกำกวมของ Missing Data:
  • ช่องว่าง vs เลข 0: ยอดซื้อสะสมเป็น "ช่องว่าง" หมายถึงยังไม่เคยซื้อ หรือระบบลืมบันทึก? ไม่เหมือนกับซื้อ "0 บาท"!
  • ใส่ขีด (-): ทำให้คอลัมน์ตัวเลขกลายเป็นข้อความ สูตร AVERAGE หรือ SUM พังทันที

สูตรตรวจจับเซลล์ว่าง

• =ISBLANK(A2) : ส่งค่า TRUE ถ้าเซลล์นั้นว่างเปล่า
• =COUNTBLANK(A2:A100) : นับจำนวนเซลล์ว่างทั้งหมดในคอลัมน์

ข้อคิดเตือนใจ: "ไม่มีข้อมูล" ไม่เท่ากับ "ข้อมูลเป็นศูนย์" ต้องแยกแยะให้ชัดเจน

ทางแก้ Trap 3: กลยุทธ์การรับมือ Missing Data สำหรับธุรกิจ

เมื่อเจอช่องว่าง ควร "ลบทิ้ง" หรือ "เติมค่า" ให้เหมาะสมกับบริบท?
Missing Strategies
ทางเลือกที่ 1

ลบแถวทิ้ง (Deletion)

ใช้เมื่อ: แถวนั้นขาดคอลัมน์สำคัญมากจนนำไปใช้ประโยชน์ไม่ได้ และมีสัดส่วนน้อย (< 5% ของข้อมูลทั้งหมด)

ตัวอย่าง: ขาดทั้งชื่อลูกค้า เบอร์โทร และยอดเงิน หรือไม่มียอดขายบันทึกไว้เลย → ลบแถวทิ้งได้เลย
ทางเลือกที่ 2

เติมค่าทดแทน (Imputation)

ใช้เมื่อ: ไม่ต้องการเสียแถวข้อมูลไป โดยแทนค่าด้วยค่ามาตรฐานที่สมเหตุสมผล

• ข้อความ: แทนด้วยคำว่า "ไม่ระบุ" หรือ "Unknown"
• ตัวเลข: แทนด้วยค่ามัธยฐาน (Median) หรือค่าเฉลี่ย (Mean) ของกลุ่ม
กฎเหล็กทางธุรกิจ: ห้ามแอบลบหรือเติมค่าตามใจชอบโดยไม่บันทึก! ทุกการลบแถวหรือแทนค่า ต้องจดลงใน Data Cleaning Log เสมอ

Trap 4: ความโกลาหลของวันที่และตัวเลข (Format Chaos)

ปัญหาเรื่องระบบคิดว่าเป็นตัวหนังสือ (Text) ทำให้บวกเลขไม่ได้ เรียงลำดับไม่ไป
Trap 4

ปัญหาวันที่และตัวเลขที่พบบ่อย

ค่าที่บันทึกมา สิ่งที่ระบบตีความ ปัญหาที่เกิด
05/03/2026 5 มี.ค. หรือ 3 พ.ค.? ว/ด/ป สลับกับ ด/ว/ป สรุปยอดรายเดือนผิดทันที
2569/03/01 ปี พ.ศ. ผสม ค.ศ. ระบบจัดเป็นข้อความ เรียงตาม Timeline ไม่ได้
"฿ 1,250" ข้อความ (Text) สูตร SUM ข้ามเซลล์นี้ ยอดรวมกลายเป็น 0!
เทคนิคตรวจสอบด้วยสายตา (Alignment Rule):
  • ใน Google Sheets: ตัวเลขและวันที่แท้จริง จะชิดขวา (Align Right) เสมอโดยธรรมชาติ
  • หากเห็นตัวเลขหรือวันที่ ชิดซ้าย (Align Left) แสดงว่าระบบมองเป็น "ข้อความ" (Text) ไม่สามารถนำไปคำนวณได้!

สูตรแปลง Text เป็นตัวเลข

ใช้ฟังก์ชัน =VALUE(SUBSTITUTE(A2, "฿", "")) เพื่อตัดสัญลักษณ์เงินออกและแปลงเป็นตัวเลขคำนวณได้

ข้อแนะนำ: ตั้ง Format วันที่ในชีตให้เป็น YYYY-MM-DD (ISO 8601) เพื่อความเป็นสากล

ทางแก้ Trap 4: ปรับ Format ตัวเลขและวันที่ให้เป็นมาตรฐาน

เครื่องมือ Format Menu และ Text-to-Columns เพื่อแปลงข้อมูลให้คำนวณได้
Formatting Tools

การจัด Format ตัวเลขให้ถูกต้อง

1. เลือกคอลัมน์ราคาสินค้าหรือยอดเงิน
2. ไปที่เมนู Format → Number → Number (1,000.12) หรือ Currency
3. ข้อควรระวัง: การใส่ลูกน้ำและสัญลักษณ์เงินควรทำผ่าน Format เมนูเท่านั้น ห้ามพิมพ์สัญลักษณ์เข้าไปในเซลล์เอง เพราะจะกลายเป็น Text

การจัดระเบียบวันที่ (Date Normalization)

1. เลือกคอลัมน์วันที่ → Format → Number → Date
2. หากวันที่มาจากต่างประเทศแล้วระบบอ่านสลับ ด/ว/ป ให้ใช้เมนู:
    File → Settings → Locale ตั้งค่าภาษาให้ตรงกับแหล่งที่มา
3. ฟังก์ชันสร้างวันที่มาตรฐาน: =DATE(ปี, เดือน, วัน)
สูตรแปลง Text วันที่เพี้ยน: หากระบบดึงวันที่มาเป็น 20260315 สามารถใช้สูตร =DATE(LEFT(A2,4), MID(A2,5,2), RIGHT(A2,2)) แปลงเป็นวันที่แท้จริงได้ทันที

Trap 5: ค่าผิดปกติ / ค่าหลุดโลก (Outliers & Anomalies)

ตัวเลขสุดโต่งที่เกิดจากพิมพ์ผิดหรือระบบล่ม ซึ่งจะลากค่าเฉลี่ยจนบิดเบือนทั้งธุรกิจ
Trap 5

ตัวอย่าง Outlier ทำลายค่าเฉลี่ย

ลูกค้า สินค้า จำนวน (ชิ้น) ยอดซื้อ (บาท)
ลูกค้า A สลัดอกไก่ 1 120
ลูกค้า B ข้าวยำแซลมอน 2 380
ลูกค้า C น้ำผลไม้สกัด 999 (เผลอพิมพ์เบิ้ล) -500 (ราคาติดลบ)
ลูกค้า D สเต็กเต้าหู้ 1 150
อานุภาพทำลายล้างของ Outlier:
  • ค่าเฉลี่ยยอดซื้อจริงควรอยู่ที่ประมาณ 216 บาท/ออเดอร์
  • แต่เมื่อมีออเดอร์หลุดโลกหลุดเข้ามา ค่าเฉลี่ยจะกลายเป็น 37.5 บาท และยอดชิ้นเฉลี่ยกลายเป็น 250 ชิ้น!
  • ผลเสีย: ฝ่ายจัดซื้อเตรียมสต็อกไก่เพิ่ม 1,000 ชิ้นจนเน่าทิ้งเพราะดูยอดเฉลี่ยที่เพี้ยน!
สถิติเบื้องต้น: เมื่อข้อมูลมี Outlier ให้ใช้ Median (มัธยฐาน) แทน Mean (ค่าเฉลี่ย) เพราะทนทานต่อค่าหลุดโลกมากกว่า
หลักคิด: ก่อนสรุปตัวเลขรายงานผู้บริหาร ต้องสแกนหาค่า Min และ Max เสมอ

ทางแก้ Trap 5: การตรวจจับและจัดการ Outliers

วิธีค้นหาค่าหลุดโลกด้วย Sort, Filter และการตัดสินใจเชิงธุรกิจ
Detection Methods
วิธีที่ 1

Sort เรียงลำดับ Min / Max

คลิกขวาที่คอลัมน์ตัวเลข → Sort A → Z (ดูค่าน้อยสุด) และ Sort Z → A (ดูค่ามากสุด) จะเห็นค่าติดลบหรือตัวเลขมหาศาลโผล่ขึ้นมาทันที

วิธีที่ 2

สร้าง Filter คัดกรองช่วงตัวเลข

เปิด Filter (Ctrl + Shift + L) → Filter by condition → Less than 0 (หายอดติดลบ) หรือ Greater than 10,000 เพื่อตรวจความผิดปกติ

วิธีที่ 3

การตัดสินใจเชิงธุรกิจ

ถ้าเป็นข้อผิดพลาดชัดเจน (เช่น อายุ 300 ปี) ให้แก้หรือลบทิ้ง แต่ถ้าเป็นลูกค้ารายใหญ่ซื้อจริง (VIP) ให้ แยกวิเคราะห์ต่างหาก ไม่รวมกับลูกค้ารายย่อย

จำไว้ว่า: Outlier บางตัวไม่ใช่ข้อผิดพลาด แต่เป็น สัญญาณทางธุรกิจ (Business Insight) เช่น พฤติกรรมการโกง (Fraud) หรือลูกค้าองค์กรสั่งซื้อล็อตใหญ่

เทคนิคส่องข้อมูลผิดด้วยสี: Conditional Formatting

เปลี่ยนเซลล์ที่มีปัญหาให้เรืองแสงอัตโนมัติ เพื่อตรวจสอบได้ด้วยสายตาใน 3 วินาที
Visual Audit

วิธีเปิดใช้งาน Conditional Formatting

1. เลือกพื้นที่ข้อมูลที่ต้องการส่อง (เช่น คอลัมน์ยอดขายหรือเบอร์โทร)
2. ไปที่เมนู Format → Conditional formatting
3. หน้าต่างขวามือจะปรากฏกฎให้เลือก (Format rules)
4. เลือกเงื่อนไขและเลือกสีไฮไลต์ (แนะนำสีแดงอ่อนสำหรับจุดผิดปกติ)

3 กฎคลาสสิกที่เจ้าของธุรกิจต้องตั้งไว้เสมอ

• จับเซลล์ว่าง: เลือก "Is empty" → สั่งให้ถมสีแดงอ่อน (เตือนว่ามี Missing Data)
• จับยอดติดลบ/ผิดปกติ: เลือก "Less than 0" → สั่งให้ตัวหนังสือสีแดงหนา
• จับรหัสซ้ำ (Duplicates): ใช้สูตรเฉพาะ (Custom formula is):
    =COUNTIF(A:A, A1) > 1
ประโยชน์สูงสุด: เมื่อมีข้อมูลใหม่อัปเดตเข้ามา เซลล์ไหนมีปัญหาจะติดไฟแดงทันที ไม่ต้องมานั่งเพ่งทีละบรรทัด!

เกราะป้องกันก่อนข้อมูลพัง: Data Validation ใน Sheets

ป้องกันข้อมูลสกปรกตั้งแต่ต้นทาง "Quality at the Source" ล็อกไม่ให้พนักงานกรอกมั่ว
Preventive Defense
ประเภทที่ 1

ดรอปดาวน์ลิสต์ (Dropdown)

บังคับให้เลือกจากรายการ เช่น ไซส์ S, M, L, XL หรือสถานะ รอชำระ, ส่งแล้ว, ยกเลิก ป้องกันปัญหาพิมพ์ตกและเคาะวรรค 100%

ประเภทที่ 2

ล็อกช่วงตัวเลข (Number Range)

กำหนดว่าจำนวนสินค้าต้อง greater than 0 และราคาสินค้าต้อง between 10 and 50000 ป้องกันการใส่ราคาติดลบหรือพิมพ์ 99999

ประเภทที่ 3

บังคับรูปแบบวันที่ (Valid Date)

เลือกเงื่อนไข is valid date ทำให้ผู้กรอกสามารถดับเบิลคลิกเลือกวันจากปฏิทิน (Date Picker) ได้ทันที ปัญหาวันที่ผิดรูปแบบจะหมดไป

ข้อแนะนำการตั้งค่า: ในส่วน "If the data is invalid" ให้เลือกติ๊กที่ "Reject input" (ปฏิเสธข้อมูล) เพื่อไม่ให้บันทึกค่าผิดพลาดลงชีตได้เด็ดขาด!

เสาหลักที่ 4: กฎเหล็ก "ห้ามแตะต้อง Raw Data เด็ดขาด!"

กฎแห่งความอยู่รอดของคนทำงานกับข้อมูล: Don't Touch the Raw Data!
Golden Rule

สิ่งที่มือสมัครเล่นชอบทำ (ห้ามทำเด็ดขาด!)

• เปิดไฟล์ยอดขายดิบที่โหลดมาจากระบบ แล้วกดลบแถว ลบช่อง แก้ตัวเลขทับลงไปทันที
• เมื่อเวลาผ่านไป สรุปตัวเลขผิดพลาด หรือเกิดข้อสงสัย ไม่สามารถตรวจสอบย้อนกลับได้เลยว่าข้อมูลเดิมคืออะไร เพราะไฟล์เดิมถูกทำลายไปแล้ว!

สิ่งที่มืออาชีพทำเสมอ (Best Practice)

• ขั้นตอนที่ 1: ล็อกชีตต้นฉบับ ตั้งชื่อว่า raw_data_backup และตั้งสิทธิ์เป็น View Only
• ขั้นตอนที่ 2: Duplicate (ทำสำเนา) ออกมาเป็นชีตใหม่ชื่อ cleaned_data แล้วลงมือคลีนในชีตนี้เท่านั้น
• ขั้นตอนที่ 3: บันทึกทุกขั้นตอนลงใน Data Cleaning Log

หากทำข้อมูลดิบเสียหาย คุณจะไม่มีหลักฐานยืนยันยอดขายย้อนหลัง และไม่สามารถรันข้อมูลใหม่ได้อีกตลอดกาล!

Data Cleaning Log: สมุดบันทึกประวัติการชำระข้อมูล

ทำไมธุรกิจเจ้าของกิจการต้องมี Audit Trail ทุกครั้งที่ทำความสะอาดข้อมูล?
Audit Trail

ทำซ้ำได้ (Reproducibility)

เมื่อสิ้นเดือนมีไฟล์ยอดขายเดือนใหม่เข้ามา เราสามารถดู Log แล้วทำตามขั้นตอนเดิมได้ทันที ไม่ต้องมานั่งคิดใหม่แต่ต้น

ส่งต่องานในทีมได้

เมื่อเจ้าของธุรกิจส่งต่อให้แอดมินหรือจ้าง Data Analyst มาช่วยงาน ทุกคนจะรู้ทันทีว่าข้อมูลผ่านการปรับแต่งอะไรมาบ้าง

ตรวจสอบย้อนหลังได้ (Audit)

หากตัวเลขทางบัญชีไม่ตรง สามารถเปิดดูได้ทันทีว่าทำไมถึงลบ 3 แถวนั้นทิ้ง ลบเมื่อไหร่ และใครเป็นคนตัดสินใจ

"If you didn't log it, it didn't happen — and if it broke, you won't know why." (ถ้าไม่จด Log ถือว่าไม่ได้ทำ และถ้าข้อมูลพัง คุณจะไม่มีวันรู้เลยว่าพังเพราะอะไร)

6 องค์ประกอบมาตรฐานของ Data Cleaning Log

โครงสร้างตารางบันทึกการทำความสะอาดข้อมูลที่นักศึกษาต้องทำใน Workshop
Standard Format
องค์ประกอบ ความหมาย & รายละเอียด ตัวอย่างการบันทึกจริง
1. Timestamp วันและเวลาที่ดำเนินการ 2026-09-23 10:15 น.
2. Column Name คอลัมน์ที่มีปัญหาและทำการแก้ไข Column C (ชื่อสินค้า), Column E (ราคา)
3. Issue Found ปัญหาที่ตรวจพบ (ระบุให้ชัดเจน) มีช่องว่างแฝงหน้า-หลัง และชื่อสะกด "XL" ปน "xl"
4. Action / Tool วิธีแก้ไข หรือสูตร/เครื่องมือที่ใช้ ใช้ฟังก์ชัน TRIM() และเปลี่ยนเป็น =UPPER()
5. Rows Affected จำนวนแถวที่ได้รับผลกระทบจากการแก้ 18 แถว (จากทั้งหมด 120 แถว)
6. Operator ชื่อผู้ดำเนินการและเหตุผล สมชาย (แอดมินร้าน) — ปรับให้เป็นมาตรฐานเดียวกัน

กรณีศึกษา 1: ชบา โคลทติ้ง (Chaba Clothing)

ร้านเสื้อผ้าแฟชั่น Multi-channel ที่ยอดสต็อกไม่ตรงเพราะปัญหา Text และ Duplicate
Fashion Case

ปัญหาที่ร้านชบาเจอ

ดึงออเดอร์จาก TikTok Shop และ LINE OA มารวมกันใน Sheets:

  • ไซส์เสื้อบันทึกปนกันมั่ว: "s", "S", "small", "เอส"
  • สีเสื้อมีทั้ง "ขาว", "White", " ขาว "
  • ลูกค้ากดยืนยันออเดอร์ใน TikTok 2 ครั้งตอนเน็ตค้าง ทำให้ออเดอร์เบิ้ล
  • ผลกระทบ: สรุปยอดขายเสื้อไซส์ S ได้ไม่ครบ สต็อกจริงล้นโกดังแต่ในระบบขึ้นว่าหมด!

ปฏิบัติการคลีนข้อมูลของร้านชบา

1. Remove Duplicates: กรอง Order ID ซ้ำ ตัดออเดอร์เบิ้ลออก 6 ออเดอร์
2. Trim Whitespace: ตัดช่องว่างหน้า-หลังคอลัมน์สีและไซส์
3. Standardize Text: ใช้สูตร =UPPER(TRIM(A2)) ปรับไซส์เป็น S, M, L, XL ทั้งหมด
4. Find & Replace: เปลี่ยนคำว่า "White" เป็น "ขาว"
5. Data Validation: สร้างดรอปดาวน์ให้แอดมินเลือกไซส์ ห้ามพิมพ์มือเอง
ผลลัพธ์: สต็อกตรงกับของจริง 100% สรุปยอดขายต่อสัปดาห์ได้ใน 1 คลิก ไม่เสียโอกาสขายอีกต่อไป

กรณีศึกษา 2: เฮลท์ตี้ไบท์ส (HealthyBites Delivery)

ธุรกิจอาหารเพื่อสุขภาพเดลิเวอรี ที่ Pivot Table พังเพราะช่องว่างแฝงท้ายชื่อเมนู
Food Delivery Case

ปัญหาที่เฮลท์ตี้ไบท์สเจอ

เจ้าของร้านต้องการสรุป "เมนูขายดีประจำสัปดาห์" ด้วย Pivot Table:

  • เมนู "ข้าวยำอกไก่ย่าง" มีพนักงานเผลอกด Spacebar แฝงไว้ข้างหลัง "ข้าวยำอกไก่ย่าง "
  • Pivot Table จึงแยกเป็น 2 บรรทัด คนละเมนู ยอดขายตกไปอยู่อันดับ 5
  • ราคาสินค้าบางรายการปล่อยว่างไว้ เพราะเป็นเมนูใหม่แอดมินยังไม่ได้ใส่ราคา
  • ผลกระทบ: เจ้าของร้านเข้าใจผิดว่าข้าวยำอกไก่ขายไม่ดี เกือบตัดสินใจตัดเมนูนี้ออกจากร้าน!

ปฏิบัติการคลีนข้อมูลกู้ชีพเมนูเด็ด

1. Trim Whitespace: สั่งตัดช่องว่างคอลัมน์ชื่อเมนูทั้งหมดทันที
2. Conditional Formatting: ไฮไลต์เซลล์ว่างในคอลัมน์ราคา พบราคาว่าง 3 จุด
3. Missing Imputation: นำราคาจาก Master Menu มาเติมให้ครบ
4. Refresh Pivot Table: รวมยอดขายเมนูข้าวยำอกไก่ได้ถูกต้อง กลับขึ้นมาเป็นอันดับ 1 ของร้านทันที!
บทเรียน: แค่ช่องว่าง 1 เคาะ เกือบทำให้ร้านอาหารสูญเสียเมนู Signature ที่สร้างกำไรสูงสุด

กรณีศึกษา 3: ยิมฟิต เอ็กซ์เพรส (GymFit Express)

ฟิตเนสรายเดือนและ PT สตูดิโอ กับปัญหาวันที่สับสนและค่าผิดปกติอายุ 300 ปี
Fitness Case

ปัญหาระบบสมาชิกของ GymFit

  • พนักงานกรอกวันเริ่มสมาชิกสลับกัน: บางคนกรอก ว/ด/ป (12/05/2026) บางคนกรอก ด/ว/ป (05/12/2026)
  • ระบบส่งแจ้งเตือนต่ออายุสมาชิกมั่ว ลูกค้าเพิ่งสมัครเมื่อวานแต่ได้รับ SMS ว่าหมดอายุแล้ว!
  • ช่องอายุกรอกเลข 300 ปี เพราะแป้นพิมพ์ค้าง ทำให้ค่าเฉลี่ยอายุสมาชิกของฟิตเนสกลายเป็น 68 ปี ทั้งที่เป็นกลุ่มวัยรุ่น

การแก้ไขและวางระบบมาตรฐาน

1. Date Parsing: ใช้ Text-to-Columns และสูตร DATE() จัดรูปแบบวันหมดอายุเป็น YYYY-MM-DD ทั้งระบบ
2. Outlier Filter: กรองคอลัมน์อายุ พบค่า 300 ปี แก้ไขเป็น 30 ปีตามบัตรประชาชน
3. Data Validation: ล็อกช่วงอายุต้องอยู่ระหว่าง 15 ถึง 85 ปี และบังคับให้เลือกวันที่ผ่าน Date Picker เท่านั้น
ผลลัพธ์: ระบบแจ้งเตือนต่ออายุสมาชิกทำงานแม่นยำ อัตราการต่อสัญญาสมาชิกเพิ่มขึ้น 25%

Workshop: "Data Cleaning Master ปฏิบัติการกู้วิกฤตข้อมูล SME"

สวมบทบาท Data Consultant ประจำร้าน Chaba Clothing ทำความสะอาดข้อมูลจริง 5 ภารกิจ
Workshop 65 Mins

5 ภารกิจกู้วิกฤตข้อมูล (40 นาที)

• Mission 1: Duplicate Raw Data → สร้างชีต cleaned_data สำรองข้อมูลดิบ
• Mission 2: ลบแถวซ้ำ (Remove Duplicates) เช็คตาม Order ID
• Mission 3: ล้างช่องว่างแฝงด้วย Trim Whitespace และฟังก์ชัน TRIM()
• Mission 4: จัดระเบียบตัวสะกดสี/ไซส์ด้วย Find & Replace และ UPPER()
• Mission 5: จัดการ Missing Values, ตรวจจับ Outlier และเขียน Data Cleaning Log

5 บทบาทสมาชิกในกลุ่ม

1. Project Lead: คุมเวลาและตรวจสอบความถูกต้องภาพรวม
2. Sheet Master: เป็นคนลงมือใช้เครื่องมือและคีย์สูตรใน Google Sheets
3. Data Auditor: ตรวจจับช่องว่าง ข้อมูลซ้ำ และ Outlier
4. Log Keeper: บันทึกทุกขั้นตอนลงใน Data Cleaning Log
5. Presenter: นำเสนอผลการคลีนและ Insight หน้าห้อง (3 นาที)
