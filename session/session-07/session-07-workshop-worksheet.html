Mission 2: Hands-on Chart Creation in Google Sheets (สร้างกราฟ 3 แบบ) Sheets

สร้างกราฟ 3 แบบใน Google Sheets: 1) Column Chart (แกนเริ่มที่ 0 + Data labels), 2) Line Chart (เส้นแนวโน้ม + Trendline), 3) Donut Chart (ผลรวม 100% สัดส่วนชัดเจน)

Checklist ตรวจทาน: ตรวจสอบว่าแกน Y ของกราฟแท่งเริ่มที่ 0 เสมอ และใส่ Data Labels แสดงตัวเลขชัดเจน
