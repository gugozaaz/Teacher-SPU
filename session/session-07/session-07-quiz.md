- [x] A) ค่าสถิติสรุป (เช่น ค่าเฉลี่ย `=AVERAGE()`) อาจหลอกตาได้ เพราะชุดข้อมูลที่มีค่าเฉลี่ยและความแปรปรวนเท่ากันเป๊ะ อาจมีพฤติกรรมและการกระจายตัวของข้อมูลต่างกันสิ้นเชิงเมื่อพล็อตเป็นกราฟ

### ข้อที่ 3:
**คำถาม:** ในการสร้าง **Column Chart (กราฟแท่ง)** มีกฎเหล็กด้านความถูกต้องของข้อมูลข้อใดที่ **"ห้ามละเมิดเด็ดขาด"** เพื่อป้องกันไม่ให้เกิดภาพลวงตาหลอกลวงผู้บริหาร?
- [x] A) แกนตัวเลข (แกน Y) ต้องเริ่มต้นที่เลข 0 เสมอ ห้ามตัดแกน (Truncated Y-Axis) เด็ดขาด
- [ ] B) ต้องใช้สีรุ้งครบ 7 สีในทุกแท่งกราฟเพื่อให้แยกแยะง่าย
- [ ] C) ต้องจัดเรียงแท่งกราฟตามลำดับตัวอักษร ก-ฮ เท่านั้น
