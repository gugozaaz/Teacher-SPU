💡 การแยก Data Analytics และ Data Science ออกจากกัน ให้ดูที่ "จุดโฟกัสของเวลา"

Data Analytics (มองสิ่งที่เกิดขึ้นแล้ว)

โฟกัส "อดีต" ถึง "ปัจจุบัน"

เกิดอะไรขึ้น? (What happened?)
ทำไมจึงเกิด? (Why did it happen?)

"กระจกมองหลัง" 🪞

Data Science (คาดเดาและให้คำแนะนำ)

โฟกัส "อนาคต"

อะไรจะเกิดขึ้น? (What will happen?)
เราควรทำอย่างไร? (What should we do?)

"GPS / เข็มทิศ" 🧭
ย้ำคอนเซปต์ กระจกมองหลัง (DA) vs GPS เข็มทิศนำทาง (DS) ให้ชัดเจน
Case Study 1: ร้านหมูกระทะ / Street Food Context: BKK

ร้านหมูกระทะย่านบรรทัดทอง

Data Analytics (มองสิ่งที่เกิดขึ้นแล้ว)

วิเคราะห์อดีต
  • คำถาม: "เดือนที่แล้ว เมนูไหนขายดีที่สุด? วันศุกร์คนเยอะช่วงกี่โมง?"
  • การทำงาน: ดึงข้อมูลจากระบบ POS มาทำกราฟแท่งสรุปยอดขายแยกตามวันและเวลา
  • ผลลัพธ์: พบว่า "ชุดหมูรวม" ขายดีที่สุด และวันศุกร์ช่วง 19.00-21.00 น. คนแน่นที่สุด (แต่โต๊ะไม่พอ)

Data Science (คาดเดาและให้คำแนะนำ)

พยากรณ์อนาคต
  • คำถาม: "ศุกร์หน้าฝนตกหนัก ควรเตรียมเนื้อหมูกี่กิโลกรัมถึงจะไม่เหลือทิ้ง?"
  • การทำงาน: นำข้อมูลยอดขายในอดีต (DA) มารวมกับ ข้อมูลพยากรณ์อากาศ สร้างโมเดลทำนายยอดขาย
  • ผลลัพธ์: ระบบพยากรณ์ว่ายอดลูกค้าจะลดลง 40% แนะนำให้สั่งวัตถุดิบลดลง และเตรียมโปรโมชั่นลดราคาดึงดูดลูกค้า
Case Study 2: ระบบขนส่งมวลชน (BTS) Context: BKK

การเดินทางชั่วโมงเร่งด่วนในกรุงเทพฯ

Data Analytics (มองสิ่งที่เกิดขึ้นแล้ว)

โจทย์: ทำรายงานสรุปจำนวนผู้โดยสารสถานีสยามและอโศก ในช่วงเวลา 07.00 - 09.00 น. ของเดือนที่ผ่านมา เพื่อดูความหนาแน่น

คุณค่าทางธุรกิจ: ช่วยให้รู้ว่าควรจัดเจ้าหน้าที่รักษาความปลอดภัยเพิ่มที่จุดไหนในช่วงเวลาใด

Data Science (คาดเดาและให้คำแนะนำ)

โจทย์: ระบบ Real-time ที่วิเคราะห์จำนวนคนแตะบัตรเข้าสถานีรอบนอก แล้ว ทำนาย ว่าอีก 30 นาทีข้างหน้า สถานีสยามจะหนาแน่นระดับใด

คุณค่าทางธุรกิจ: ระบบส่งแจ้งเตือนลูกค้าล่วงหน้าผ่านแอปฯ พร้อม แนะนำเส้นทางหลีกเลี่ยง (Prescriptive) หรือปล่อยขบวนรถเสริมอัตโนมัติ

Case Study 3: ธุรกิจหอพัก / คอนโดปล่อยเช่า Context: BKK

การบริหารผู้เช่าย่านมหาวิทยาลัย/ออฟฟิศ

Data Analytics (มองสิ่งที่เกิดขึ้นแล้ว)

วิเคราะห์อดีต
  • คำถาม: "ปีที่ผ่านมา เดือนไหนที่มีผู้เช่าย้ายออกมากที่สุด?"
  • ผลลัพธ์: พบว่าสถิติการย้ายออกจะพุ่งสูงในช่วงเดือน พฤษภาคม (ช่วงเรียนจบ/ย้ายที่ทำงาน)
  • Action: เตรียมเปิดรับผู้เช่าใหม่ล่วงหน้าในช่วงนั้น

Data Science (คาดเดาและให้คำแนะนำ)

พยากรณ์อนาคต
  • คำถาม: "ผู้เช่าห้องไหน มีแนวโน้มจะย้ายออกในเดือนหน้า?"
  • การทำงาน: สร้างโมเดลโดยใช้ข้อมูล: การจ่ายค่าเช่าล่าช้า, จำนวนครั้งที่แจ้งซ่อม, หรือระยะเวลาที่อาศัยอยู่มา
  • Action: ระบบแจ้งเตือนให้เจ้าของทักไปเสนอโปรโมชั่นต่อสัญญา (ลด 10%) แก่ลูกค้ารายนั้น "ก่อน" ที่เขาจะตัดสินใจย้ายออก
Case Study 4: ร้านสะดวกซื้อ 24 ชม. Context: BKK

การจัดสต็อกสินค้าตามฤดูกาล

Data Analytics (มองสิ่งที่เกิดขึ้นแล้ว)

โจทย์: ดึงข้อมูลจากระบบ POS เพื่อดูความสัมพันธ์ระหว่างยอดขาย "ร่มและเสื้อกันฝน" กับ "วันที่ฝนตกใน กทม." ของปีที่แล้ว

คุณค่าทางธุรกิจ: เป็นการพิสูจน์สมมติฐานว่าฝนตกทำให้สินค้านี้ขายดีจริง (Diagnostic Analytics)

Data Science (คาดเดาและให้คำแนะนำ)

โจทย์: ระบบดึง API พยากรณ์อากาศล่วงหน้า 3 วัน ถ้าพยากรณ์ว่าฝนจะตกหนักเกิน 70% ระบบจะ "สั่งสต็อกร่มเพิ่มอัตโนมัติ" ไปยังศูนย์กระจายสินค้า

คุณค่าทางธุรกิจ: เปลี่ยนจากการรอให้คนของขาดแล้วค่อยสั่ง เป็นระบบอัตโนมัติที่ลดความผิดพลาดของคน (Prescriptive)

Case Study 5: คลินิกความงาม / โรงพยาบาล Context: BKK

ปัญหาลูกค้าเทนัด (No-show)

Data Analytics (มองสิ่งที่เกิดขึ้นแล้ว)

วิเคราะห์อดีต
  • คำถาม: "อัตราการผิดนัด (No-show rate) ของเดือนนี้คือเท่าไหร่?"
  • ผลลัพธ์: พบว่าคิวช่วงบ่ายวันเสาร์มีคนไม่มาตามนัดสูงถึง 25% ทำให้แพทย์สูญเสียเวลารายได้

Data Science (คาดเดาและให้คำแนะนำ)

พยากรณ์อนาคต
  • คำถาม: "พรุ่งนี้มีลูกค้าคนไหนที่มีความเสี่ยงจะเบี้ยวคิว 80% ขึ้นไป?"
  • การทำงาน: โมเดลวิเคราะห์จากประวัติเก่า ระยะทางจากบ้าน และระยะเวลาที่จองล่วงหน้า
  • Action: แอดมินโทรไปคอนเฟิร์มเฉพาะคิวที่มีความเสี่ยงสูง (ประหยัดเวลาโทรหาทุกคน) ถ้าลูกค้ายกเลิก ก็เอาคิวไปรับ Walk-in ทันที
Case Study 6: ไลฟ์สดขายเสื้อผ้าออนไลน์ Context: BKK

การเพิ่มยอดขายขณะ Live

Data Analytics (มองสิ่งที่เกิดขึ้นแล้ว)

โจทย์: หลังจบไลฟ์ 3 ชั่วโมง นำข้อมูลมาสรุปบน Dashboard ว่าชุดเดรสสีไหนถูก CF (Confirm) มากที่สุด

คุณค่าทางธุรกิจ: เพื่อเตรียมสั่งผลิตสำหรับสต็อกในรอบถัดไป

Data Science (คาดเดาและให้คำแนะนำ)

โจทย์: "ระบบวิเคราะห์ข้อความแชท (NLP)" แบบ Real-time ขณะไลฟ์

คุณค่าทางธุรกิจ: ระบบจับ Sentiment และข้อความคนดู แล้วกระซิบบอกแม่ค้าผ่านจอมอนิเตอร์ว่า "ตอนนี้คนดู 40% พิมพ์ถามถึงเสื้อคลุมสีเบจ รีบหยิบมาโปรโมทคู่กันเลย!"

Case Study 7: ธุรกิจฟิตเนส (Fitness) Context: BKK

การยกระดับประสบการณ์สมาชิก (Personalization)

Data Analytics (มองสิ่งที่เกิดขึ้นแล้ว)

วิเคราะห์อดีต
  • คำถาม: "คลาสโยคะ หรือ คลาสซุมบ้า มีคนเข้าเรียนเฉลี่ยเยอะกว่ากัน?"
  • ผลลัพธ์: สรุปได้ว่าคลาสโยคะช่วงเย็นเต็มทุกวัน จึงเปิดคลาสโยคะเพิ่ม

Data Science (คาดเดาและให้คำแนะนำ)

พยากรณ์อนาคต
  • คำถาม: "นาย B ที่เพิ่งสมัครสมาชิก จะชอบเล่นเครื่องเล่นไหนหรือคลาสใด?"
  • การทำงาน: สร้าง Recommendation Model บนแอปพลิเคชัน คล้าย Netflix แต่เป็นสำหรับออกกำลังกาย
  • Action: แอปพลิเคชันจัดตารางออกกำลังกายแบบรายบุคคล (Personalized Workout Plan) และแนะนำคลาสที่เข้ากับสไตล์ของเขาอัตโนมัติ

Workshop & บทสรุป Session 1 Advance

กิจกรรม Workshop: แยกแยะ DA และ DS

สรุปประเด็น (Takeaways)

  • DA = มองอดีต เพื่อเข้าใจปัญหาและสถานการณ์
  • DS = มองอนาคต เพื่อพยากรณ์และแนะนำทางออก
  • ธุรกิจที่ดีต้องใช้ DA ตอบคำถามพื้นฐาน ก่อนต่อยอดด้วย DS สำหรับการวางกลยุทธ์

Workshop (กลุ่มละ 4-5 คน)

  • รับโจทย์ "สถานการณ์ธุรกิจในกรุงเทพฯ" 5 ข้อ
  • ให้แต่ละกลุ่มช่วยกันวิเคราะห์ว่า แต่ละโจทย์ต้องการการแก้ปัญหาแบบ DA หรือ DS พร้อมบอกเหตุผล
  • ตั้งคำถามต่อยอด 1 ข้อ สำหรับโจทย์นั้น
