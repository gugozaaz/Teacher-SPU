# Quiz 10 ข้อ: Data Analytics vs Data Science

### ข้อ 1
**คำถาม:** ร้านหมูกระทะย่านบรรทัดทอง ทำการสร้างกราฟแท่งเพื่อดูว่าวันศุกร์มีลูกค้าเข้ามากี่คนในช่วงเดือนที่ผ่านมา การทำแบบนี้คือส่วนหนึ่งของศาสตร์ใด?
- [x] A. Data Analytics (DA)
- [ ] B. Data Science (DS)
- [ ] C. Data Engineering (DE)
**คำอธิบาย:** การดูสิ่งที่เกิดขึ้นไปแล้วในอดีต (What happened?) เพื่อสรุปยอดลูกค้าคือ Data Analytics

---

### ข้อ 2
**คำถาม:** ระบบรถไฟฟ้า BTS ใช้ข้อมูลจำนวนผู้โดยสารจากสถานีรอบนอก เพื่อ "ทำนาย" ว่าอีก 30 นาทีข้างหน้า สถานีสยามจะหนาแน่นแค่ไหน และจัดขบวนรถเสริมอัตโนมัติ การทำงานนี้คือข้อใด?
- [ ] A. Data Analytics (DA)
- [x] B. Data Science (DS)
- [ ] C. Data Storage
**คำอธิบาย:** การใช้ข้อมูลแบบ Real-time เพื่อทำนายอนาคต (Predictive) และให้ระบบตัดสินใจให้ (Prescriptive) คือหัวใจของ Data Science

---

### ข้อ 3
**คำถาม:** เปรียบเทียบการขับรถ แนวคิดของ "Data Science" ทำหน้าที่เหมือนสิ่งใดมากที่สุด?
- [ ] A. กระจกมองหลัง (Rearview Mirror)
- [ ] B. ล้อรถยนต์
- [x] C. ระบบ GPS และเข็มทิศนำทางอัจฉริยะ
**คำอธิบาย:** DS เปรียบเหมือน GPS ที่คอยบอกอนาคตข้างหน้าและแนะนำเส้นทางให้เราตัดสินใจ

---

### ข้อ 4
**คำถาม:** ผู้จัดการคลินิกความงามทำรายงานพบว่ามีลูกค้า "เทนัด" ถึง 25% ในบ่ายวันเสาร์ นี่คือการวิเคราะห์อดีต (DA) หากคลินิกต้องการยกระดับเป็น Data Science (DS) ควรทำสิ่งใด?
- [ ] A. สรุปกราฟยอดลูกค้าเทนัดทุกวัน
- [ ] B. ไล่ออกพนักงานที่รับคิว
- [x] C. สร้างโมเดลทำนายความเสี่ยงของคิวพรุ่งนี้ว่าใครมีโอกาสเบี้ยวสูง
**คำอธิบาย:** การยกระดับเป็น DS คือการนำข้อมูลมาทำนายล่วงหน้าว่าใครจะเบี้ยวคิว เพื่อให้แอดมินโทรตามได้ตรงคน

---

### ข้อ 5
**คำถาม:** ระบบแอปพลิเคชันฟิตเนสที่คอยจัดตารางออกกำลังกายแบบรายบุคคล และ "แนะนำคลาส" (Recommendation) ที่เหมาะสมกับสไตล์ของสมาชิกแต่ละคน ถือเป็นการใช้ประโยชน์จากสิ่งใด?
- [ ] A. สรุปรายงานยอดขาย
- [x] B. Data Science (DS)
- [ ] C. การเก็บข้อมูลเบื้องต้น
**คำอธิบาย:** ระบบ Recommendation เป็นโมเดลทาง Data Science ที่วิเคราะห์พฤติกรรมเพื่อเสนอสิ่งที่ตรงใจลูกค้า

---

### ข้อ 6
**คำถาม:** แม่ค้าไลฟ์สดขายเสื้อผ้า นำข้อมูลมาสรุปบน Dashboard ยอด CF หลังจบไลฟ์ เพื่อดูว่าสีอะไรขายดี การกระทำนี้คือศาสตร์ใด?
- [x] A. Data Analytics (DA)
- [ ] B. Data Science (DS)
- [ ] C. Data Privacy
**คำอธิบาย:** เป็นการสรุปรายงานสิ่งที่เกิดขึ้นไปแล้วหลังจบไลฟ์ (กระจกมองหลัง)

---

### ข้อ 7
**คำถาม:** ในธุรกิจร้านสะดวกซื้อ การเชื่อมต่อ API พยากรณ์อากาศเพื่อ "สั่งสต็อกร่มเพิ่มอัตโนมัติ" เมื่อระบบวิเคราะห์ว่าฝนจะตก เป็นระดับการวิเคราะห์ข้อมูลแบบใด?
- [ ] A. Descriptive Analytics (วิเคราะห์อดีตว่าเกิดอะไรขึ้น)
- [ ] B. Diagnostic Analytics (วิเคราะห์ว่าทำไมจึงเกิด)
- [x] C. Prescriptive Analytics (แนะนำทางเลือก/ตัดสินใจอัตโนมัติ)
**คำอธิบาย:** ระบบทำหน้าที่ให้คำแนะนำ (สั่งของอัตโนมัติ) ซึ่งเป็นขั้นสูงสุดของการทำ Data Science แบบ Prescriptive Analytics

---

### ข้อ 8
**คำถาม:** "เดือนที่ผ่านมา คอนโดเรามีผู้เช่าย้ายออกจำนวน 10 ห้อง" ประโยคนี้คือผลลัพธ์จากกระบวนการใด?
- [x] A. Data Analytics (DA)
- [ ] B. Data Science (DS)
- [ ] C. Artificial Intelligence (AI)
**คำอธิบาย:** เป็นเพียงการรายงานสิ่งที่เกิดขึ้นไปแล้วในอดีต (DA) ยังไม่ได้มีการพยากรณ์อะไร

---

### ข้อ 9
**คำถาม:** การที่ธุรกิจใดๆ จะใช้ข้อมูลให้เกิดประโยชน์สูงสุด ทักษะใดที่ผู้เรียน (ในฐานะเจ้าของธุรกิจ) ต้องให้ความสำคัญมากที่สุด?
- [ ] A. เขียนโปรแกรม Python ให้เก่งที่สุด
- [ ] B. สร้างระบบ AI แข่งกับบริษัทระดับโลก
- [x] C. ความเข้าใจธุรกิจ (Business Domain) และการตั้งคำถามให้ตรงจุด
**คำอธิบาย:** ทักษะทางธุรกิจและการตั้งสมมติฐาน/คำถามที่ถูกต้อง เป็นหัวใจสำคัญในการต่อยอดหาคำตอบจากข้อมูล

---

### ข้อ 10
**คำถาม:** ข้อใดเปรียบเทียบ Data Analytics (DA) และ Data Science (DS) ได้ถูกต้องที่สุด?
- [ ] A. DA ใช้ในการทำนายยอดขาย, DS ใช้ทำรายงานส่งสรรพากร
- [x] B. DA เน้นเข้าใจอดีตและปัจจุบัน, DS เน้นพยากรณ์และให้คำแนะนำในอนาคต
- [ ] C. DA เหมาะกับบริษัทขนาดใหญ่, DS เหมาะกับบริษัทขนาดเล็ก
**คำอธิบาย:** DA มุ่งเน้นการสรุปอดีต (What happened?) ส่วน DS มุ่งเน้นการพยากรณ์และการตัดสินใจ (What will happen? / What should we do?)
