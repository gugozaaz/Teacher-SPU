### ข้อที่ 1:
**คำถาม:** ในวงจร Data Science 5 ขั้นตอน (ASK &rarr; COLLECT &rarr; PREPARE &rarr; ANALYZE &rarr; ACT) เมื่อเจ้าของธุรกิจตั้งคำถามและสมมติฐานเสร็จแล้วในขั้น 'ASK' ก้าวต่อไปในขั้น **'COLLECT'** คืออะไร?
- [ ] A) รีบลงมือเขียนโค้ด Python หรือใช้ AI สร้างโมเดลทำนายยอดขายทันทีโดยไม่ต้องคัดกรองข้อมูล
- [x] B) ระบุประเภทข้อมูลที่ต้องการและวางแผนรวบรวมข้อมูลจากแหล่งต่างๆ เพื่อนำมาพิสูจน์สมมติฐาน
- [ ] C) สรุปผลลัพธ์และทำแผนธุรกิจเสนอขอเงินกู้ทันที โดยยึดตามสัญชาตญาณความรู้สึก

### ข้อที่ 2:
**คำถาม:** จากกรณีศึกษา 7-Eleven ข้อมูล **"บิลขายหน้าร้าน" (POS Basket Data)** เช่น *[Bill #71092] 12:24 น. | ข้าวผัดกะเพรา (45฿) + ไข่ต้ม (10฿) + ชาเขียว (20฿) | ยอด 75฿* จัดเป็นข้อมูลประเภทใด และนำไปใช้ประโยชน์ในธุรกิจได้อย่างไร?
- [x] A) ข้อมูลมีโครงสร้าง (Structured Data) สามารถนำไปคำนวณยอดขายเฉลี่ยต่อบิล (AOV) และวิเคราะห์สินค้าที่ลูกค้ามักซื้อร่วมกัน (Market Basket Analysis) เพื่อจัดโปรโมชันคู่
- [ ] B) ข้อมูลไร้โครงสร้าง (Unstructured Data) ที่ต้องใช้โปรแกรมตัดต่อวิดีโอหรือกราฟิกขั้นสูงในการเปิดอ่านข้อมูล
- [ ] C) ข้อมูลเชิงคุณภาพแบบไม่มีลำดับ (Nominal Data) ที่ไม่สามารถนำยอดเงินมาบวกหรือหาค่าเฉลี่ยได้เลย
**เฉลย:** A) ตารางบิลขายหน้าร้านจาก POS มีโครงสร้างแถวและคอลัมน์ชัดเจน มีฟิลด์เวลา รหัสสินค้า ยอดเงิน จึงเป็น Structured Data ที่นำไปคำนวณ AOV (Average Order Value) และทำ Basket Analysis เพื่อจับคู่สินค้าขายดี เช่น ข้าวผัดกะเพราคู่กับไข่ต้มและเครื่องดื่ม

### ข้อที่ 3:
**คำถาม:** ร้านอาหารพบว่ายอดขายตก จึงเข้าไปอ่านข้อความรีวิวของลูกค้าบน Google Maps และ Wongnai เช่น *"อาหารรสชาติดีมาก แต่รอคิวอาหารนานเกือบ 40 นาที และพนักงานหน้าบึ้ง"* ข้อมูลข้อความรีวิวเหล่านี้จัดเป็นข้อมูลประเภทใด และมีประโยชน์อย่างไรต่อเจ้าของธุรกิจ?
- [ ] A) ข้อมูลมีโครงสร้าง (Structured Data) ที่สามารถสั่งรวมยอด (SUM) เพื่อคิดเป็นกำไรสุทธิได้ทันที
- [ ] B) ข้อมูลกึ่งตัวเลข (Numerical Data) ที่ใช้คำนวณภาษีมูลค่าเพิ่มส่งสรรพากร
- [x] C) ข้อมูลไร้โครงสร้าง (Unstructured Data) ที่เป็นเชิงคุณภาพ ช่วยเฉลย "สาเหตุและเบื้องหลัง" ว่าทำไมลูกค้าถึงไม่ประทับใจ
**เฉลย:** C) ข้อความรีวิว ความคิดเห็น และคอมเมนต์ ไม่มีโครงสร้างตารางแน่นอน จึงจัดเป็นข้อมูลไร้โครงสร้าง (Unstructured Data) และเป็นข้อมูลเชิงคุณภาพ (Qualitative) ซึ่งแม้จะคำนวณตัวเลขตรงๆ ไม่ได้ แต่เป็นขุมทรัพย์ที่เฉลยว่า "ทำไมยอดขายถึงตก" โดยในปัจจุบันเจ้าของร้านสามารถใช้ AI (เช่น Gemini) ช่วยสรุปประเด็น Pain Points ได้อย่างรวดเร็ว

### ข้อที่ 4:
**คำถาม:** กรณีศึกษา **"คาเฟ่ชาไทย"** มีการจัดเก็บข้อมูล 3 ระบบ ได้แก่ 1) บิลขายหน้าร้าน (Store POS) 2) ออเดอร์เดลิเวอรีผ่าน Platform Online (Grab / ShopeeFood) และ 3) ระบบสะสมแสตมป์ 10 แถม 1 (E-Stamp) การเชื่อมโยงข้อมูลทั้ง 3 ระบบเข้าด้วยกันช่วยให้เจ้าของร้านได้เปรียบอย่างไร?
- [ ] A) ช่วยหลีกเลี่ยงการเสียค่า GP ให้แพลตฟอร์มเดลิเวอรีโดยไม่ต้องทำสัญญา
- [x] B) เห็นภาพรวมยอดขายทั้งหน้าร้านและออนไลน์ คำนวณกำไรสุทธิหลังหัก GP ได้แม่นยำ พร้อมใช้ระบบแสตมป์กระตุ้นให้ลูกค้าประจำกลับมาซื้อซ้ำ
- [ ] C) บังคับให้ลูกค้าทุกคนต้องสั่งผ่านเดลิเวอรีเท่านั้นเพื่อลดภาระพนักงานหน้าร้าน
**เฉลย:** B) การรวมข้อมูลแบบ Omnichannel (POS หน้าร้าน + Delivery Platform + Loyalty E-Stamp) ทำให้เจ้าของร้านคาเฟ่ชาไทยเห็นพฤติกรรมลูกค้าครบทุกช่องทาง รู้เมนูยอดนิยม รู้กำไรจริงหลังหัก GP 30% และดึงดูดลูกค้าให้ซื้อซ้ำจนครบ 10 แก้วเพื่อแลกรับแก้วฟรี

### ข้อที่ 5:
**คำถาม:** ในการดำเนินงานร้านกาแฟ ข้อมูลคู่ใดต่อไปนี้ จำแนกเป็น **"ข้อมูลเชิงปริมาณแบบไม่ต่อเนื่อง" (Discrete Data)** และ **"ข้อมูลเชิงปริมาณแบบต่อเนื่อง" (Continuous Data)** ได้ถูกต้องตามลำดับ?
- [x] A) จำนวนแก้วเครื่องดื่มที่ขายได้ในแต่ละวัน (นับเป็นจำนวนเต็ม) และ ระยะเวลาที่ลูกค้ารอคอยเครื่องดื่ม (วัดค่าเป็นนาที มีเศษทศนิยมได้)
- [ ] B) อุณหภูมิของนมที่สตีมในเหยือก (วัดเป็นองศาเซลเซียส) และ น้ำหนักเมล็ดกาแฟที่บดต่อช็อต (ชั่งเป็นกรัม)
- [ ] C) ระดับความพึงพอใจของลูกค้า (1 ถึง 5 ดาว) และ ยี่ห้อของนมสดที่ร้านเลือกใช้
**เฉลย:** A) Discrete Data เกิดจากการ "นับ" เป็นชิ้น/คน/แก้ว ซึ่งเป็นจำนวนเต็มเท่านั้น (เช่น ขายได้ 150 แก้ว ไม่มี 150.3 แก้ว) ส่วน Continuous Data เกิดจากการ "วัด ชั่ง ตวง จับเวลา" ซึ่งมีความต่อเนื่องและมีเศษทศนิยมได้ (เช่น เวลารอ 4.5 นาที, อุณหภูมินม 65.5°C)

### ข้อที่ 6:
**คำถาม:** ข้อมูล **"วิธีการชำระเงินของลูกค้า" (สแกน PromptPay, บัตรเครดิต, เงินสด)** และ **"ระดับความหวานของเครื่องดื่ม" (0%, 25%, 50%, 100%)** จัดเป็นข้อมูลเชิงคุณภาพ (Qualitative Data) ประเภทใดตามลำดับ?
- [ ] A) ข้อมูลเชิงปริมาณแบบต่อเนื่อง (Continuous) และ ข้อมูลเชิงปริมาณแบบไม่ต่อเนื่อง (Discrete)
- [ ] B) ข้อมูลแบบจัดลำดับได้ (Ordinal) และ ข้อมูลแบบไม่มีลำดับ (Nominal)
- [x] C) ข้อมูลแบบไม่มีลำดับ (Nominal) และ ข้อมูลแบบจัดลำดับได้ (Ordinal)
**เฉลย:** C) ช่องทางชำระเงินจัดเป็น Nominal Data เพราะเป็นการตั้งชื่อกลุ่ม/หมวดหมู่ที่ไม่มีลำดับสูง-ต่ำ (ไม่สามารถบอกได้ว่า PromptPay สูงกว่าหรือดีกว่าเงินสดในเชิงคณิตศาสตร์) ส่วนระดับความหวานจัดเป็น Ordinal Data เพราะมีลำดับขั้นความหวานจากน้อยไปมากชัดเจน (0% < 25% < 50% < 100%)

### ข้อที่ 7:
**คำถาม:** หากเจ้าของร้านเครื่องดื่มต้องการตัดสินใจลงทุนซื้อ "เครื่องทำสเลอปี้" มูลค่าหลายหมื่นบาท และต้องการดูว่าคนไทยเริ่มตื่นตัวค้นหาคำว่า **"ชาไทยสเลอปี้"** ในช่วงเดือนใดและในจังหวัดใดมากที่สุด เพื่อวางแผนสต็อกวัตถุดิบและยิงแอดล่วงหน้า ควรใช้เครื่องมือใดที่ **ฟรี เข้าถึงง่าย และรวดเร็วที่สุด**?
- [ ] A) โพสต์ถามความคิดเห็นใน Facebook ส่วนตัวของเจ้าของร้าน
- [x] B) ใช้ Google Trends ประเทศไทย วิเคราะห์แนวโน้มคำค้นหา (Interest over time) และการกระจายตัวตามพื้นที่
- [ ] C) จ้างบริษัทวิจัยตลาดทำแบบสอบถามกลุ่มตัวอย่าง 2,000 คนทั่วประเทศ
**เฉลย:** B) Google Trends เป็นแหล่งข้อมูลภายนอกแบบทุติยภูมิ (External Secondary Data) ที่ให้บริการฟรี ช่วยให้เจ้าของธุรกิจเห็นกราฟแนวโน้มความสนใจของคนทั้งประเทศและรายจังหวัดได้แบบเรียลไทม์ ทำให้จับกระแสได้ทันเวลา เช่น สั่งเครื่องสเลอปี้มาลงหน้าร้านทันช่วงพีคหน้าร้อนเดือนเมษายน

### ข้อที่ 8:
**คำถาม:** กรณีศึกษาธุรกิจร้านอาหารสุกี้/ชาบู (เช่น สุกี้ตี๋น้อย / MK Suki) ที่มีการจัดเก็บข้อมูลจริง ได้แก่ 1) บัตรคิว QueQ 2) **รายการสั่งอาหารของลูกค้าแต่ละโต๊ะ (Table Order Log)** เช่น โต๊ะ 15 สั่งเนื้อพรีเมียม x 5, ผักบุ้ง x 2, ลูกชิ้น x 1 และ 3) บันทึกสต็อกครัว (Kitchen Log) การเก็บข้อมูลละเอียดระดับนี้มีประโยชน์ต่อการบริหารร้านอย่างไร?
- [x] A) ช่วยให้วิเคราะห์ปริมาณการบริโภคจริงของแต่ละโต๊ะ วางแผนสั่งเนื้อสัตว์และผักสดเข้าครัวกลางได้แม่นยำ และควบคุมเศษอาหารเหลือทิ้ง (Food Waste) ให้ต่ำสุด
- [ ] B) ใช้สุ่มระงับสิทธิ์ลูกค้าที่สั่งอาหารปริมาณมากไม่ให้กลับมาใช้บริการอีก
- [ ] C) นำไปใช้ตั้งราคาบุฟเฟต์ใหม่แบบสุ่มรายชั่วโมงตามสภาพอากาศภายนอกร้าน
**เฉลย:** A) การบันทึกข้อมูลแบบบูรณาการตั้งแต่บัตรคิว QueQ, รายการสั่งอาหารแต่ละโต๊ะแบบเรียลไทม์ (Table Order Log) และ Kitchen Log ช่วยให้ร้านรู้ว่าโต๊ะขนาดกี่คนมักสั่งถาดเนื้อสัตว์และผักอะไรบ้าง ทำให้ครัวกลางเตรียมวัตถุดิบได้พอดีกับความต้องการ ไม่ขาดแคลน และลด Food Waste จนเหลือเพียง 1%

### ข้อที่ 9:
**คำถาม:** ตาม พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล (PDPA) และจริยธรรมข้อมูล เจ้าของร้านค้าหรือแม่ค้าออนไลน์ในข้อใด **ปฏิบัติตัวได้อย่างถูกต้องและปลอดภัยตามกฎหมาย** มากที่สุด?
- [ ] A) แคปภาพสลิปโอนเงินของลูกค้าที่มีชื่อ-นามสกุลจริงและเลขบัญชีครบถ้วน ไปโพสต์ขอบคุณลูกค้าหน้าเพจ Facebook เพื่อสร้างความน่าเชื่อถือ
- [ ] B) บังคับให้ลูกค้าต้องกรอกเลขบัตรประชาชน 13 หลัก และวันเดือนปีเกิดเต็ม ก่อนที่จะอนุญาตให้สะสมแต้มแลกชานมไข่มุกฟรี 1 แก้ว
- [x] C) ขอเฉพาะข้อมูลที่จำเป็นต่อการสะสมแต้ม (เช่น ชื่อเล่นและเบอร์โทร), แจ้งวัตถุประสงค์ชัดเจน, และทำการเบลอชื่อ-นามสกุลและเลขบัญชีทุกครั้งหากจำเป็นต้องแสดงสลิปโอนเงิน
**เฉลย:** C) 3 กฎเหล็ก PDPA สำหรับ SME คือ 1) Data Minimization: ขอเฉพาะข้อมูลที่จำเป็น (ห้ามขอเลขบัตรประชาชนสำหรับซื้อกาแฟ/ชานม) 2) Consent: ขอความยินยอมและบอกวัตถุประสงค์ชัดเจน และ 3) Security: รักษาความปลอดภัยและห้ามโพสต์สลิปโอนเงินที่มีข้อมูลส่วนบุคคลลูกค้าในที่สาธารณะโดยไม่เซนเซอร์/เบลอข้อมูล

### ข้อที่ 10:
**คำถาม:** เจ้าของร้านกาแฟแห่งหนึ่ง ต้องการสำรวจความพึงพอใจของลูกค้าเพื่อปรับปรุงเมนู แต่กลับเลือกแจกแบบสอบถามให้เฉพาะ 'ลูกค้าประจำที่สนิทกัน' เท่านั้น โดยไม่เคยสอบถามลูกค้าขาจรเลย พฤติกรรมการเก็บข้อมูลนี้จะส่งผลเสียตามข้อใดมากที่สุด?
- [ ] A) เป็นเรื่องปกติของการทำ Data Analytics เพราะลูกค้าประจำให้ข้อมูลที่แม่นยำที่สุดเสมอ
- [x] B) เกิดความลำเอียงในการเก็บข้อมูล (Data Collection Bias) ทำให้ได้ข้อมูลด้านดีเพียงด้านเดียว และเสียโอกาสแก้ไขปัญหาที่แท้จริง
- [ ] C) เกิดปัญหาขยะเข้า-ขยะออก (Garbage In, Garbage Out) เพราะกระดาษแบบสอบถามสกปรก
**เฉลย:** B) การเก็บข้อมูลเพียงกลุ่มเดียว (เช่น เฉพาะคนที่ชอบร้าน) ทำให้เกิด Data Collection Bias (ความลำเอียงในการเก็บข้อมูล) ซึ่งทำให้เจ้าของธุรกิจมองไม่เห็นปัญหาที่แท้จริงว่าทำไมลูกค้าขาจรถึงไม่กลับมาซื้อซ้ำ และนำไปสู่การแก้ปัญหาไม่ถูกจุด
