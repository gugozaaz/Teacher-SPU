### ข้อที่ 1:
**คำถาม:** ในวงจร Data Science 5 ขั้นตอน (ASK, COLLECT, PREPARE, ANALYZE, ACT) ทำไมขั้นตอนที่ 1 **'ASK' (ตั้งคำถาม)** ถึงสำคัญที่สุด?
- [ ] A) เพราะเป็นขั้นตอนที่ต้องใช้เครื่องมือ AI เขียนโค้ดซับซ้อนที่สุด
- [x] B) เพราะถ้าตั้งคำถามผิด ข้อมูลและการวิเคราะห์ที่ตามมาก็จะได้คำตอบที่ผิดและไร้ประโยชน์
- [ ] C) เพราะเป็นขั้นตอนเดียวที่เจ้าของธุรกิจไม่ต้องเกี่ยวข้อง ให้โปรแกรมเมอร์ทำแทนได้
**เฉลย:** B) "ถ้าตั้งคำถามผิด ข้อมูลก็ให้คำตอบที่ผิด" การตั้งคำถามที่ตรงกับปัญหาธุรกิจจริงเป็นจุดเริ่มต้นที่สำคัญที่สุด

### ข้อที่ 2:
**คำถาม:** สาเหตุหลักที่ทำให้เจ้าของธุรกิจหลายคน *"มีข้อมูลการขายมากมาย แต่ยังไม่สามารถเพิ่มยอดขายได้"* คือข้อใด?
- [ ] A) ขาดเงินทุนในการซื้อคอมพิวเตอร์และเซิร์ฟเวอร์ราคาแพง
- [x] B) ขาด Data Thinking ไม่ได้เริ่มต้นจากปัญหาธุรกิจ และไม่รู้ว่าจะตั้งคำถามอะไรกับข้อมูล
- [ ] C) ข้อมูลในอดีตไม่สามารถนำมาใช้ทำนายหรือวิเคราะห์อนาคตได้เลย
**เฉลย:** B) การมีข้อมูลเยอะแต่ขาด Data Thinking ทำให้ไม่รู้จะนำข้อมูลไปตอบโจทย์อะไร หรือไม่รู้จะสั่ง Prompt ให้ AI ช่วยวิเคราะห์อะไร

### ข้อที่ 3:
**คำถาม:** คำถามทางธุรกิจในข้อใด ถือเป็น **"คำถามที่ดีและเจาะจง (Actionable Question)"** ตามหลัก Data Thinking?
- [ ] A) ทำไมช่วงนี้ยอดขายร้านเราถึงดูเงียบๆ จัง?
- [ ] B) ทำอย่างไรให้ธุรกิจของเรารวยขึ้นและขายดีกว่าคู่แข่ง?
- [x] C) โปรโมชั่นลด 20% บน LINE MAN ช่วง 11.00-13.00 น. ช่วยดึงลูกค้าใหม่ได้กี่ % และคุ้มค่า GP หรือไม่?
**เฉลย:** C) เป็นคำถามที่มีความชัดเจน เจาะจงตัวแปร/เวลา/ช่องทาง วัดผลได้ด้วยตัวเลข และนำไปสู่การตัดสินใจปรับกลยุทธ์ต่อได้ทันที

### ข้อที่ 4:
**คำถาม:** ในเดือนเมษายน ร้านสะดวกซื้อพบว่า *"ยอดขายเครื่องดื่มเย็นพุ่งสูงขึ้น"* พร้อมกับ *"บิลค่าไฟฟ้าของร้านเพิ่มขึ้นเท่าตัว"* ข้อใดสรุปได้ถูกต้องตามหลักข้อมูล?
- [x] A) ทั้งสองอย่างเป็นแค่ความสัมพันธ์ (Correlation) โดยมี "สภาพอากาศที่ร้อนจัด" เป็นสาเหตุแท้จริง (Causation)
- [ ] B) การขายเครื่องดื่มเย็นเป็นสาเหตุโดยตรงที่ทำให้บิลค่าไฟแพงขึ้น
- [ ] C) การเปิดแอร์ทำให้ลูกค้าหิวน้ำเย็น จึงเป็นเหตุผลที่ยอดขายเครื่องดื่มพุ่งขึ้น
**เฉลย:** A) Correlation ≠ Causation การที่ตัวเลขเพิ่มขึ้นพร้อมกันไม่ได้แปลว่าเป็นสาเหตุของกันและกัน สาเหตุแท้จริงคือสภาพอากาศร้อนจัดช่วงหน้าร้อน (>40°C)

### ข้อที่ 5:
**คำถาม:** "สมมติฐาน" (Hypothesis) ในกระบวนการ Data Thinking หมายถึงอะไร?
- [ ] A) ข้อสรุปสุดท้ายที่ได้หลังจากทำการวิเคราะห์ข้อมูลเสร็จสิ้นแล้ว 100%
- [x] B) การคาดเดาคำตอบหรือสาเหตุอย่างมีหลักการ เพื่อกำหนดทิศทางในการหาข้อมูลมาพิสูจน์
- [ ] C) การเดาสุ่มโดยไม่มีเหตุผล เพื่อให้มีตัวเลือกเยอะๆ ไว้ก่อน
**เฉลย:** B) สมมติฐานคือการคาดเดาคำตอบอย่างมีหลักการ เพื่อช่วยให้เจ้าของธุรกิจรู้ว่าจะต้องไปเก็บข้อมูลตัวเลขใดมาพิสูจน์ ไม่ต้องงมในตัวเลข

### ข้อที่ 6:
**คำถาม:** ลำดับขั้นตอนของกระบวนการ Hypothesis Thinking ที่ถูกต้องคือข้อใด?
- [ ] A) หาข้อมูล (Data) &rarr; พบปัญหา (Problem) &rarr; ตั้งสมมติฐาน (Hypothesis)
- [x] B) พบปัญหา (Problem) &rarr; ตั้งสมมติฐาน (Hypothesis) &rarr; หาข้อมูลพิสูจน์ (Data)
- [ ] C) ตั้งสมมติฐาน (Hypothesis) &rarr; แก้ปัญหาทันที (Action) &rarr; ค่อยหาข้อมูล (Data)
**เฉลย:** B) เริ่มต้นจาก 1. ระบุปัญหาธุรกิจให้ชัดเจน (Problem) &rarr; 2. คาดเดาสาเหตุ (Hypothesis) &rarr; 3. กำหนดชุดข้อมูลที่จะนำมาพิสูจน์ (Data)

### ข้อที่ 7:
**คำถาม:** แม่ค้า Live สดพบปัญหา *"ลูกค้าพิมพ์ CF เยอะมาก แต่ทิ้งออเดอร์ไม่ยอมโอนเงินถึง 40%"* หากตั้งสมมติฐานว่า *"แอดมินทักแชทสรุปยอดช้าเกินไป"* ควรเก็บข้อมูลใดมาพิสูจน์?
- [ ] A) จำนวนผู้กดติดตามเพจเฟซบุ๊กรายเดือน
- [x] B) บันทึกเวลาที่แอดมินตอบแชท (Response Time) เทียบกับอัตราการโอนเงินสำเร็จของแต่ละออเดอร์
- [ ] C) ราคาสินค้าของคู่แข่งในตลาด
**เฉลย:** B) ต้องเก็บข้อมูลเวลาที่แอดมินใช้ในการทักแชทเทียบกับผลการโอนเงิน เพื่อดูว่าแชทที่ตอบช้ามีอัตราการทิ้งออเดอร์สูงกว่าจริงหรือไม่

### ข้อที่ 8:
**คำถาม:** คำถามว่า **"ทำไมยอดขายชานมช่วงเช้า (07.30-09.00 น.) ถึงมีเพียง 10% ทั้งที่คนเดินผ่านเยอะมาก?"** จัดอยู่ในการวิเคราะห์ระดับใด?
- [ ] A) Descriptive Analytics (การวิเคราะห์แบบพรรณนา — "เกิดอะไรขึ้น?")
- [x] B) Diagnostic Analytics (การวิเคราะห์แบบวินิจฉัย — "ทำไมถึงเกิดสิ่งนี้?")
- [ ] C) Predictive Analytics (การวิเคราะห์แบบพยากรณ์ — "อะไรจะเกิดขึ้นต่อไป?")
**เฉลย:** B) Diagnostic Analytics คือการวิเคราะห์เพื่อหา "สาเหตุ" เบื้องหลังของปัญหา (Why did it happen?)

### ข้อที่ 9:
**คำถาม:** แอปส่งอาหารวิเคราะห์ว่า **"พรุ่งนี้ช่วงเที่ยงพยากรณ์อากาศระบุว่าฝนจะตก ออเดอร์ในย่านออฟฟิศจะพุ่งสูงขึ้น 50%"** เป็นการวิเคราะห์ระดับใด?
- [ ] A) Descriptive Analytics ("เกิดอะไรขึ้น?")
- [x] B) Predictive Analytics ("อะไรจะเกิดขึ้นต่อไป?")
- [ ] C) Prescriptive Analytics ("เราควรทำอย่างไรดี?")
**เฉลย:** B) Predictive Analytics เป็นการนำข้อมูลและปัจจัยแวดล้อมมาคาดการณ์แนวโน้มที่จะเกิดขึ้นในอนาคต (What will happen?)

### ข้อที่ 10:
**คำถาม:** การที่ร้านสะดวกซื้อตัดสินใจ **"ย้ายตู้แช่ไส้กรอกและไข่ออนเซ็นมาวางติดกับจุดกดน้ำร้อน พร้อมจัดโปรฯ เซ็ตคู่หูดึกดื่น"** หลังพบว่าคนซื้อบะหมี่คัพชอบกินคู่กับไส้กรอก จัดเป็นตัวอย่างของการวิเคราะห์ระดับใด?
- [ ] A) Descriptive Analytics (พรรณนาข้อมูลในอดีต)
- [ ] B) Diagnostic Analytics (หาสาเหตุของพฤติกรรม)
- [x] C) Prescriptive Analytics (การแนะนำและลงมือตัดสินใจเลือกกลยุทธ์ที่ดีที่สุด)
**เฉลย:** C) Prescriptive Analytics คือระดับสูงสุดของการวิเคราะห์ ที่นำ Insight มากำหนดเป็น Action ทางธุรกิจที่ชัดเจนเพื่อเพิ่มยอดขายหรือแก้ปัญหา
